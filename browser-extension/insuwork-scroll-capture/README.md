# 보험워크 채팅 스크롤 캡처

해피톡과 보맵플래너의 채팅 영역을 마우스로 지정하고, 선택한 세로 구간을 자동으로 스크롤해 긴 PNG로 저장하는 Chrome 확장 프로그램입니다.

## 설치

1. ZIP 파일을 압축 해제합니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 눌러 이 폴더를 선택합니다.
5. 설치 후 이미 열어 둔 해피톡·보맵플래너 탭은 한 번 새로고침합니다.

기존 버전을 업데이트할 때는 새 파일로 폴더를 교체하고 `chrome://extensions`의 확장 프로그램 카드에서 새로고침 버튼을 누릅니다.

## 사용

1. 보험워크 `에즈 시청방 → 스크롤 캡처`를 엽니다.
2. `채팅창 캡처 시작`을 누릅니다.
3. 해피톡 또는 보맵플래너에서 채팅 영역의 왼쪽 위부터 아래쪽으로 드래그합니다.
4. 화면 가장자리까지 끌면 자동으로 스크롤됩니다.
5. 마우스를 놓으면 선택 구간을 이어 붙여 PNG 저장 창을 엽니다.

고객 개인정보가 포함될 수 있으므로 결과는 사용자의 PC에만 저장합니다. 보험워크 서버로 자동 전송하지 않습니다.

해피톡처럼 입력창이 대화 영역 위에 고정된 화면은 입력창과 떠 있는 버튼을 자동으로 제외하고 대화 내용만 이어 붙입니다.
보맵플래너처럼 채팅 목록이 역방향 스크롤(`column-reverse`)인 화면도 화면 위에서 아래로 이어지는 좌표로 변환해 캡처합니다.
