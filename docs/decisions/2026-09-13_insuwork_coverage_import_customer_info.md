# 보장분석 파일에서 고객 정보 연결

- 원인: 표 상단 고객 정보 입력·고객 선택·보험나이 계산은 있었으나 엑셀/PDF/OCR 추출 → 병합 → 저장 경로가 고객 정보를 전달하지 않았다. OCR 응답 스키마에도 고객 정보가 없었다.
- 엑셀의 전체 시트에서 명시된 고객명·생년월일과 뱅크샐러드의 이름/성별/생년월일 병합 셀을 읽는다. 문서에서 이름을 찾지 못하면 보장분석/보장진단 파일명 패턴의 이름만 보완한다. 가려진 이름은 원문대로 둔다.
- 실제 제공 파일 확인: 뱅크샐러드 엑셀에 이름과 생년월일이 존재한다. 카카오페이 엑셀에는 생년월일 항목이 없으므로 날짜나 보험나이를 만들어내지 않는다. 파일 비밀번호·계약일·상품코드·출력일로 생년월일을 추정하지 않는다.
- 이미지/PDF 분석 스키마와 반환값에 customerInfo(name, birthDate)를 추가한다. 브라우저에서 날짜 유효성을 검사하고 기존 보험나이 계산에 연결한다. 텍스트 PDF 대체 파서도 같은 정보를 전달한다.
- 병합 시 빈 고객 정보만 보완하고 연결 고객 ID를 유지한다. 서로 다른 이름/생년월일이 명시된 자료는 병합을 중단하고 확인을 안내한다. 고객 카드의 기본 정보는 빈 추출값으로 지우지 않는다.
- 기존 저장표에 소급해서 임의 데이터를 쓰지 않는다. 업데이트 후 파일을 다시 불러오면 적용된다. 생년월일이 원본에 없는 경우 고객 선택 또는 직접 입력이 필요하다.
- 검증: 제공 엑셀 2종을 메모리/임시 파일로 읽어 추출 결과 확인, 테스트에는 가상 고객 사용. 고객 정보 전파·마스킹·날짜 제외·충돌·OCR 서버 응답 테스트 추가. 브라우저 다중 파일 분석 후 고객명·생년월일·보험나이 표시 확인.
