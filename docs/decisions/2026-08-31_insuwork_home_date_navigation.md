# 보험워크 홈 할 일 날짜 탐색

- 확정일: 2026-08-31
- 대표 요청: 캘린더와 같은 화살표로 홈에서 과거·미래 일정을 확인하고 라이브 반영.
- 범위: 보험워크 `/insuwork/` 홈. 데이폴더 일반·설계사 및 별도 모바일 앱은 변경하지 않는다.

## 표시와 동작

- 기존 왼쪽 정렬을 유지하고 `[오늘] ‹ › 날짜 · 할 일` 순서로 표시한다.
- 이전·다음 버튼은 하루씩 이동하고 오늘 버튼은 현재 날짜로 복귀한다.
- 오늘은 `오늘 할 일`과 `오늘일정`, 다른 날은 `할 일`과 `일정`으로 표시한다.
- 고객케어·상령일을 포함한 목록은 선택 날짜를 따른다. 여러 날에 걸친 일정은 해당 기간에 표시한다.
- 캘린더 보기는 선택한 날짜를 캘린더에 전달한다.
- 조회 날짜는 홈 URL에 보존한다. 날짜 없는 신규 홈 진입은 오늘이다.
- 현재 연도와 다르면 연도도 표시한다.

## 데이터 경계

- 기존 로그인·소유자 필터·RLS를 유지한다.
- 날짜 이동은 읽기 전용 홈 조회이며 고객케어 자동 쓰기를 포함하는 전체 로드를 호출하지 않는다.
- 기존 요청 번호 검사를 이용해 빠른 날짜 이동 중 이전 응답이 최신 목록을 덮지 않도록 한다.
- DB DDL·RLS·인증 비밀 변경 없음.
