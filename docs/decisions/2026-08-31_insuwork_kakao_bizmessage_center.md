# 보험워크 카카오 비즈메시지 발송센터 판단

Date: 2026-08-31
Scope: 보험워크 카카오 알림톡/친구톡/브랜드 메시지 연동 검토

## 다음 대화에서 먼저 상기할 내용

대표님이 다음에 "카카오 연동", "알림톡", "친구톡", "카카오 발송센터", "카카오톡 일괄 발송" 이야기를 꺼내면, 먼저 이 문서를 기준으로 상기한다.

- 보험워크에서 만들 기능은 개인 카카오톡 1:1 자동 발송기가 아니다.
- 보험워크 전용 카카오톡 채널과 공식 비즈메시지 경로를 쓰는 발송센터다.
- 상대방이 보험워크에 가입하지 않아도 알림톡은 전화번호 기반으로 발송 가능하다.
- 친구톡/브랜드 메시지는 채널 친구 또는 마케팅 수신 동의 조건이 붙는다.
- 카카오디벨로퍼스 일반 메시지 API는 개인 친구에게 임의 대량 발송하는 용도가 아니다.
- 비즈메시지 API 연동은 일반적으로 공식 딜러사/메시징 사업자와 계약해서 진행한다.

## 확인한 공식 방향

카카오 비즈메시지는 알림톡, 친구톡, 상담톡, 브랜드 메시지 계열로 나뉜다. 보험워크 고객DB에서 전화번호 기반으로 발송하려면 일반 카카오톡 개인 계정이 아니라 카카오톡 채널/비즈메시지 구조를 써야 한다.

카카오 데브톡 안내 기준:

- 카카오디벨로퍼스는 비즈메시지 알림톡/친구톡/상담톡을 직접 제공하지 않는다.
- 알림톡/친구톡/상담톡 API 연동은 공식 딜러사를 통해 사용한다.
- 개인 간 메시지를 외부 시스템에서 임의로 발송하는 API는 제공되지 않는다.

## 보험워크에 맞는 제품 구분

### 알림톡

보험워크 1차 MVP에 가장 적합하다.

- 정보성 메시지 발송용.
- 카카오톡 채널 친구가 아니어도 전화번호 기반 발송 가능.
- 템플릿 사전 승인 필요.
- 보험 상담 예약, 필요서류 안내, 청약/계약 관리 안내, 상령일 안내처럼 정보성 메시지에 적합.
- 실패 시 SMS/LMS 대체 발송을 붙일 수 있다.

주의:

- 광고, 영업 홍보, 이벤트성 내용은 알림톡으로 보내기 어렵다.
- 템플릿 승인 범위를 벗어난 자유 문구 발송은 제한된다.

### 친구톡

2차 확장 후보.

- 카카오톡 채널 친구 대상 발송.
- 광고성/마케팅 메시지에 사용할 수 있다.
- 광고 표기, 수신동의, 야간 발송 제한 등 정책 관리 필요.

### 브랜드 메시지

향후 확장 후보.

- 채널 친구뿐 아니라 마케팅 수신 동의 사용자 대상의 개인화 광고성 메시지로 확장 가능.
- 보험워크 초기 MVP에는 과하다.

### 상담톡

별도 상담 채널 운영 후보.

- 고객이 카카오톡 채널을 통해 상담을 시작하는 구조.
- 보험워크의 상담관리와 연결할 수 있지만, 일괄 발송센터와는 목적이 다르다.

## 조사한 연동 후보

### SOLAPI

초기 MVP 후보 1순위.

- 개발자 문서와 API가 단순한 편이다.
- SMS, 알림톡, 친구톡, 브랜드 메시지, RCS를 하나의 메시지 API 계열로 다룬다.
- SDK, 웹훅, 대체 발송을 제공한다.
- 공개 안내 기준 알림톡 단가가 명확하게 제시되어 있었다.
- 보험워크 MVP에서 빠르게 붙여보기 좋다.

확인할 것:

- 알림톡 템플릿 등록/승인 방식.
- 친구톡/브랜드 메시지 조건.
- 발송 결과 웹훅.
- 실패 시 SMS/LMS 대체 발송 단가.
- 사업자/채널 명의 조건.

### NHN Cloud KakaoTalk Bizmessage

기업형/관리형 후보.

- 알림톡 API 문서가 체계적이다.
- 대량 발송, 통계 조회, 결과 조회, 대체 발송 구조가 있다.
- `appkey`, `X-Secret-Key`, `senderKey`, `templateCode` 기반으로 연동한다.

확인할 것:

- 소규모 이용 진입 조건.
- 월 기본료/최소 충전 조건.
- 보험업 템플릿 심사 지원.
- 발송 결과 웹훅 또는 폴링 운영 방식.

### 인포뱅크 Bizgo

대량/전문 메시징 사업자 후보.

- 카카오 비즈메시지 쪽 대표 사업자군으로 볼 수 있다.
- 알림톡/브랜드 메시지/대체 발송 API 문서가 있다.
- 수신자 묶음 발송 구조를 제공한다.

확인할 것:

- 최소 계약 조건.
- 단가 협상 가능 구간.
- 템플릿 승인 대행 지원.
- 보험업 메시지 운영 경험.

### Kakao i Connect Message

카카오 계열 BizMessage API 문서 후보.

- 알림톡, 브랜드 메시지, 친구톡, XMS, RCS, 다채널 대체 발송 문서가 있다.
- 일반 소규모 서비스가 바로 가입해서 쓰기 쉬운 형태인지는 별도 확인 필요.

## 보험워크 구현 방향

처음부터 친구톡/브랜드 메시지까지 모두 만들지 않는다.

1. 보험워크 카카오 발송센터 MVP를 만든다.
2. 알림톡만 먼저 붙인다.
3. 승인 템플릿 3개만 운영한다.
4. 고객관리에서 대상자를 선택하고 발송한다.
5. 발송 결과와 실패 사유를 고객별 이력으로 저장한다.
6. 실패 시 문자 대체 발송을 옵션으로 둔다.
7. 이후 친구톡/브랜드 메시지로 확장한다.

메뉴명:

- 카카오 발송센터

주요 화면:

- 발송 대상 선택
- 고객 상태/상담 상태/청약일/상령일/태그 기준 필터
- 템플릿 선택
- 고객별 치환값 미리보기
- 즉시 발송/예약 발송
- 발송 결과 확인
- 실패 고객 재발송
- 고객 상세 발송 이력

필수 치환값:

- 고객명
- 담당자명
- 상담일
- 청약일
- 준비서류
- 연락처
- 예약일시

## 1차 승인 템플릿 후보

### 상담 예약 안내

용도:

- 고객과 약속한 상담 일정 안내.

핵심 변수:

- 고객명
- 상담일시
- 담당자명
- 연락처

### 필요서류 안내

용도:

- 청약/심사/보험금 청구 등에 필요한 서류 안내.

핵심 변수:

- 고객명
- 서류목록
- 제출방법
- 담당자명

### 청약/계약 관리 안내

용도:

- 청약 완료, 계약 관리, 후속 확인 안내.

핵심 변수:

- 고객명
- 청약일
- 계약 관련 안내
- 담당자명

## DB 설계 초안

추가 테이블 후보:

- `insuwork_message_templates`
- `insuwork_message_campaigns`
- `insuwork_message_recipients`
- `insuwork_message_logs`

저장 항목:

- 템플릿명
- 메시지 유형
- 딜러사/공급자
- 승인 템플릿 코드
- 발송 대상 고객 ID
- 수신 전화번호
- 치환 변수
- 발송 상태
- 실패 사유
- 발송 요청 시각
- 발송 완료 시각
- 발송자 ID

## 서버 구현 원칙

- 딜러사 API 키는 프론트에 두지 않는다.
- Supabase Edge Function 같은 서버 함수에서만 호출한다.
- 발송 요청 전 대상자와 템플릿을 서버에서 다시 검증한다.
- 발송 결과는 웹훅 또는 폴링으로 저장한다.
- 고객별 발송 이력을 보험워크 안에 남긴다.

- 알림톡 단가

- 월 기본료 여부
- 선불 충전/후불 가능 여부
- 최소 계약 조건
- 템플릿 등록/수정 API 제공 여부
- 템플릿 검수 평균 소요 시간
- 발송 결과 웹훅 제공 여부
- 실패 시 SMS/LMS 대체 발송 가능 여부
