# KB 보장분석 상세표 가져오기

- 카카오페이·뱅크샐러드 엑셀 파서와 양식은 유지한다. KB PDF는 상세표의 구분, 회사 담보명, 신정원 담보명, 가입금액을 함께 사용한다.
- 요약표의 권장금액을 가입금액으로 입력하지 않는다. 상세표와 요약표를 중복 합산하지 않는다.
- 명시적인 `실손` 구분은 축약된 회사 담보명보다 우선한다. 입원+통원 합산 한도를 임의로 개별 한도로 나누지 않는다. 세대를 추측하지 않는다.
- 보험료미제공도 상품과 담보를 보존한다.
- 입원일당은 입원 항목으로 분류한다. 병원 등급, 병실, 지급일수 등 다른 조건이 있는 특약은 이름과 금액을 별도 행으로 보존한다. 일반 입원일당 칸에 무조건 합산하지 않는다.
- 기본 양식의 이름·분류·순서를 덮어쓰지 않는다. 일치하는 행을 채우고 없는 특약은 작업표에 추가한다. 기본 양식 저장은 기존 임태성 전용 권한을 유지한다.
- KB 원본 쪽수·회사 담보명·신정원 담보명·가입금액은 sourceDetails로 보존하며 담보명 마우스 오버로 확인한다.
- 검증은 파일 인식 성공뿐 아니라 기본 양식 병합, 반복 가져오기, 실손·입원 특약별 한도 보존, 기존 엑셀 회귀 테스트까지 포함한다.
