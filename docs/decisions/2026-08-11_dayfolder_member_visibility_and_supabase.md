# DayFolder 멤버 공개와 Supabase 저장 원칙

## 결정

- 설계사 버전의 파일·노트·메모·일정은 브라우저 저장소가 아니라 Supabase를 진실 원천으로 사용한다.
- 모든 자료의 공개 범위는 작성자가 `나만 보기` 또는 `멤버 공개` 중 직접 선택한다.
- 자료 종류에 따라 공개 범위를 자동 강제하지 않는다.
- 기존 브라우저 자료를 최초 이전할 때는 전부 `나만 보기`로 설정한다.
- `멤버 공개` 자료는 로그인한 멤버가 함께 열람할 수 있지만 수정·삭제는 작성자만 가능하다.
- 첨부파일과 노트 본문에 삽입한 이미지도 부모 자료와 동일한 공개 범위를 따른다.
- 로그인 전에는 Supabase 개인 자료와 멤버 자료를 내려주지 않는다.

## 제품 범위

- 이 변경은 설계사 협업 공간의 영구 저장·공유 기능이므로 설계사 버전에만 적용한다.
- 일반 범용 DayFolder는 계정 없는 공개 체험 성격을 유지하며 기존 기기 저장 방식을 계속 사용한다.

## 운영 원칙

- `멤버`는 별도의 운영자 발급 계정 유형이 아니라 Supabase 인증을 마친 사용자다.
- 공개 범위의 기본값은 안전을 위해 `나만 보기`로 둔다. 작성자는 작성·수정 화면에서 언제든 `멤버 공개`로 바꿀 수 있다.
- 데이터베이스 정책이 UI와 별개로 타인의 비공개 자료 조회 및 타인 자료 수정을 차단해야 한다.
