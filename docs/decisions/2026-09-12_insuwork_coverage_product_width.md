# 회사·상품 열 가변 너비와 상품명 줄바꿈 — 2026-09-12

- 상품명 입력을 자동 높이 textarea로 바꿔 긴 상품명 전체와 사용자가 입력한 줄바꿈을 표시한다.
- 표의 가용 너비에서 분류·담보·합계금액·행 버튼 영역을 제외한 공간을 현재 표시 중인 상품 수로 나눈다. 최소 158px을 유지하고 상품이 많으면 가로 스크롤을 사용한다.
- 컨테이너 너비 기반 CSS로 전체 화면 전환, 창 크기 변경, 상품 추가·삭제·숨김과 담보 너비 변경에 반응한다. 입력 시 표 전체 재렌더링을 추가하지 않는다.
- Node 문법 검사 및 Chrome 확인: 상품 1열 1349px → 2열 674.5px → 9열 158px/가로 스크롤. 긴 상품명 높이와 scrollHeight 모두 73px으로 잘림 없음. 전체 화면에서도 잘림 없음.
