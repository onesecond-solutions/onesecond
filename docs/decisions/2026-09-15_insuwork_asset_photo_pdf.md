# 자료 메뉴 다중 사진 PDF 저장

- 업무노트·자료실·메모에서 한 번에 사진 두 장 이상만 넣으면 선택 순서대로 한 장당 한 페이지인 PDF 하나로 저장한다. 기존 이미지 변환기의 PDF 생성 로직을 공통 함수로 재사용한다.
- 파일 선택, 화면 붙여넣기, 화면 드롭, 폴더 대상 드롭에 적용한다. 현재 분류와 대상 폴더 및 본인 비공개 저장을 유지한다.
- 사진 한 장과 이미지 외 파일이 섞인 묶음은 기존 개별 파일 저장을 유지한다. 폴더 전체 복사는 기존 구조와 개별 파일을 보존한다.
- 원본 PC 파일은 수정하지 않는다. 이미지 비율을 유지하며 PDF 생성 실패 시 업로드하지 않고 재시도할 수 있게 잠금을 해제한다.
- 고객·상담 카드 및 리치텍스트 편집기 이미지 붙여넣기, 보험이슈 업로드는 변경하지 않는다.
- 실제 PDF 생성과 페이지 크기·순서, 세 분류·폴더 저장 메타데이터, 단일/혼합 파일 유지, 손상 이미지 실패를 브라우저에서 검증한다. 서버 쓰기는 테스트에서 가짜 응답으로 대체한다.
