# 보험워크 전용 도메인

대표 승인: `insuwork.onesecond.solutions`로 보험워크 주소를 이전한다. 원세컨드 본체는 기존 주소를 유지한다.

- 제품 소스는 이 저장소 한 곳에서 관리한다. `insuwork-site` 저장소는 생성된 공개 정적 파일만 담는 GitHub Pages 배포 대상이다.
- main의 제품 변경 → `insuwork-site.yml` → 정적 파일 생성 → 배포 저장소 main → Pages 순으로 자동 반영한다. 전용 SSH deploy key는 배포 저장소에만 쓰기 가능하며 원본 저장소 Actions secret에 보관한다.
- 기존 `/insuwork/` 리소스 및 하위 경로를 보존한다. 새 도메인 `/`는 보험워크 진입 화면이며 모바일·자료 링크도 동일 도메인에서 동작한다.
- 같은 Supabase 프로젝트와 사용자 ID를 사용한다. DB 이동·계정 변경·권한 변경 없음. 인증 반환 허용 목록에 새 도메인만 추가하고 기존 항목 및 Site URL은 유지한다.
- 브라우저 저장소는 origin별로 분리되므로 새 주소에서 재로그인이 필요하다. 기존 주소의 저장하지 않은 임시 작업을 자동 이전하지 않는다.
- DNS: 기존 14개 레코드를 유지하고 `insuwork CNAME onesecond-solutions.github.io` 한 개만 추가한다.
- HTTPS·실제 화면 검증 후 기존 보험워크 진입 주소를 전환한다. OAuth 콜백 중인 요청은 원래 origin에서 처리를 마칠 수 있도록 예외로 둔다.
- 롤백: 기존 주소 리다이렉트를 해제하면 원래 사이트를 그대로 이용할 수 있다. 원세컨드 CNAME이나 데이터는 수정하지 않는다.
