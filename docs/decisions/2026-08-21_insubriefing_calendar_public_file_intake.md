# 보험브리핑 캘린더 공개 자료 입력 범위

- 확정일: 2026-08-21
- 적용 대상: `/insubriefing/` 공개 리플렛 캘린더
- 쓰기 권한: 임태성 파일럿 계정 전용
- 읽기 권한: 로그인 여부와 무관하게 공개

## 확정 사항

1. 기존 이미지·PDF 드래그 업로드를 유지한다.
2. 대표님이 이 기능에서 말하는 `엑셀 파일`은 스프레드시트만이 아니라 Word, PowerPoint, 한글, OpenDocument를 포함한 오피스 문서 전체를 뜻한다.
3. 지원 문서는 `xls`, `xlsx`, `csv`, `doc`, `docx`, `ppt`, `pptx`, `hwp`, `hwpx`, `odt`, `ods`, `odp`다.
4. 텍스트는 `txt`, `md`, `log`, `json`, `xml`, `yaml`, `yml` 및 브라우저가 `text/*`로 판별한 파일을 지원한다. `rtf`는 오피스 문서처럼 다운로드한다.
5. 날짜를 먼저 선택한 뒤 붙여넣으면 클립보드 이미지·파일·일반 텍스트를 해당 날짜에 등록한다.
6. 오피스·텍스트 자료는 공개 범위 안내를 확인한 뒤 등록한다. 붙여넣은 텍스트에서 주민번호·전화번호 형태가 감지되면 강화된 경고를 표시한다.
7. 실행파일·압축파일 등 미지원 형식과 파일당 20MB 초과 자료는 등록하지 않고 이유를 표시한다.
8. 오피스 문서는 형식·파일명·용량 카드로 표시하고 다운로드한다. 텍스트는 내부 미리보기와 다운로드를 제공한다.
9. 단일 `http/https` URL 붙여넣기와 `.url` 바로가기 파일은 링크 카드로 저장하고 클릭 시 새 창으로 연다. 다른 스킴은 차단한다. 설명 속 URL은 텍스트 미리보기 안에서 안전한 링크로 표시한다.

## 호환 구현

- 기존 DB의 `mime_type`, `file_size`, `storage_path`를 사용한다.
- 원본 파일명은 UUID와 구분해 저장 경로에 보존한다.
- 기존 `file_type` 제약과의 호환을 위해 이미지는 `image`, 나머지 공개 파일은 기존 비이미지 값 `pdf`로 저장하되 실제 렌더링 종류는 MIME과 확장자로 판단한다.
- 따라서 이번 기능에는 운영 DB DDL을 적용하지 않는다. 기존 이미지·PDF 행과 공개 URL은 그대로 호환된다.
