# 보험워크 홍보 시연과 사용자 가이드

대표 요청으로 로그인 전 사용 흐름 홍보와 로그인 후 메뉴별 단계 시연을 추가한다.
- 공개 랜딩: 상담 등록 → 청약완료 → 계약 기준일 → 후속 케어 → 캘린더의 5단계, 로그인 연결.
- 지원 > 사용자 가이드: 상담관리, 계약관리, 캘린더, 자료·업무노트, 보장분석 각각 3단계.
- 자동재생/일시정지/이전/다음/다시 보기/단계 선택. 마지막 단계에서 정지. 감소된 모션 환경은 자동재생하지 않는다.
- 가상 고객 김예시를 이용한 HTML 시연 예시이며 실제 화면 녹화·실제 고객 캡처가 아니다. 이 한계를 화면에도 표시한다.
- 실제 업무 데이터 저장·변경 없이 시연하며 메뉴 열기로 업무 화면에 연결한다.
- 화면 재렌더링 시 단계와 재생 상태를 유지한다.

검증: JavaScript 문법, diff 검사, 로컬 브라우저의 단계 이동 및 메뉴 전환. 라이브 배포 후 공개 시연과 로그인 연결 확인 예정.
