# 보험포털 첫 구현 — 2026-09-19

대표가 자료실 조사·구성안 이후 구현을 지시했다. 9월 1일의 구현 보류를 해제한다.

- 대표 개인 자료실을 원천으로 주제별 읽기 화면을 만든다. 파일 목록을 공개자료실로 옮기지 않는다.
- 새 기능 기본 정책에 따라 대표 계정에 먼저 노출한다. 로그인 전 소개 페이지는 유지한다.
- 기존 통합 검색에 합류하며 포털 전용 검색창을 만들지 않는다.
- 첫 화면은 비대칭 특집, 도표, 비교 읽기, 변천사, 생활·돌봄, 원자료 시리즈로 구성한다.
- 자료실의 현대해상 알려줘 8편, DB·메리츠 솔루션북, KB 수술비 인체도 등 실제 자료를 연결한다.
- 19개 읽기 주제를 구성한다. 원본 PDF는 기존 인증·서명 URL·RLS로 읽어 브라우저에서 해당 페이지를 렌더링한다. 비공개 PDF·이미지·서명 URL은 Git에 복제하지 않는다.
- 기존 실손·암주요치료비·간병 변천사의 본문은 보존하고 포털 읽기 모드에서는 옛 탐색 메뉴·설계사 전용 영역을 숨긴다.
- 이번 버전은 선별된 읽기 주제와 원문 도표 연결이다. 자료실 전체 자동 콘텐츠 생성·자동 게시 기능을 구현한 것으로 보고하지 않는다. 원자료 파일명 변경 시 연결 정의를 갱신해야 한다.
- DB 쓰기, 버킷 공개, RLS 변경, 개인 자료 변경은 없다.
