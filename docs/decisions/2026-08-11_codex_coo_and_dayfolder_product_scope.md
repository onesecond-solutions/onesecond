# 코상무 총괄 인계와 데이폴더 제품별 변경 범위

- 확정일: 2026-08-11
- 확정자: 대표님 임태성
- 상태: 현행

## 결정

1. Codex는 `코상무`로서 기존 총괄의 업무를 이어받아 원세컨드 전체를 점검하고 작업하는 메인 작업자가 된다.
2. `세션스타트`는 현재 폴더만 확인하는 명령이 아니다. 원세컨드 본체, 관련 제품, 저장소, 라이브 배포, 미완료 작업과 위험을 전체 점검하고 보고하는 시작 명령이다.
3. 반복 적용할 업무 원칙과 제품 구분은 대화에만 의존하지 않고 GitHub에 기록한다.
4. 인증·도구 연결처럼 코상무가 복구할 수 있는 문제는 먼저 복구하고, 대표님의 권한이나 위험 승인이 꼭 필요한 경우에만 차단 사항으로 올린다.

## 데이폴더 제품 구분

### 설계사 버전

- 라이브: `https://onesecond.solutions/dayfolder-advisor/`
- 진실 원천: `onesecond-solutions/onesecond` 저장소의 `dayfolder-advisor/`
- 설계사 전용 로그인, 계정, 문구, 화면과 운영 기능을 관리한다.

### 일반 범용 버전

- 진실 원천: `onesecond-solutions/dayfolder-app`
- 일반 사용자를 대상으로 하는 데이폴더 본체를 관리한다.

## 변경 적용 규칙

모든 데이폴더 변경은 구현 전에 다음 중 하나로 판정한다.

1. **설계사 전용:** `onesecond/dayfolder-advisor`만 수정한다.
2. **범용 전용:** `dayfolder-app`만 수정한다.
3. **공통:** 실제 공유 자산과 배포 구조를 확인한 뒤 양쪽 모두 필요한 변경을 적용하고 각각 검증·저장한다.

전용 변경을 근거 없이 양쪽에 복제하지 않으며, 공통 변경을 한쪽에만 적용해 버전 간 회귀를 만들지 않는다. 완료 보고에는 판정, 수정 저장소, 검증 범위를 함께 기록한다.

## 운영 번들 계보와 회귀 방지

- 2026-08-11 기준 설계사 운영 기능의 원본은 `dayfolder-app`의 `feat/dayfolder-settings-panel-cleanup` 브랜치다.
- `master` 빌드는 고객관리·설계사 헤더·배경 갤러리 등 운영 기능보다 오래된 계보일 수 있으므로 최신이라고 가정하지 않는다.
- 공통 앱 번들을 교체하기 전 기존 운영 번들과 신규 빌드의 기능 표식을 비교한다.
- 필수 비교 항목: 고객관리, 설계사 전용 문구, 배경 갤러리, 설정 화면, 이번 변경 기능.
- 배포 후 일반 `/dayfolder/app/`과 설계사 `/dayfolder-advisor/`가 같은 의도된 자산을 참조하는지 각각 확인한다.
