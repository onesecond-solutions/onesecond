# 보장금액 직접 입력 표기 — 2026-09-12

- 합계금액과 상품별 보장금액 입력 칸은 가운데 정렬한다.
- 사용자가 직접 숫자를 입력할 때 만원 단위로 천 단위 쉼표와 `만`을 붙인다. 예: `1000` → `1,000만`, `1.5` → `1.5만`.
- 파일 불러오기, 초기 렌더링, 저장본 로드 과정에는 변환을 적용하지 않는다. 원/억 등 단위가 명시된 기존 금액도 입력 없이 변환하지 않는다.
- 입력 즉시 작업본에 반영하되 표 전체를 다시 그리지 않는다. 커서는 숫자 뒤·단위 앞에 유지하며 빈 입력은 빈칸으로 둔다.
- 숫자/소수/빈칸/삭제/기존 원 단위 보존과 커서 위치를 VM에서 확인했다. Chrome에서 `1000` 입력 → `1,000만` 표시와 가운데 정렬을 확인했다.
