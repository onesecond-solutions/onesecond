# 변천사 읽기 화면 — 2026-09-20

대표가 실손 시안을 기준으로 암주요치료비·간병보험까지 팀작업 후 라이브 반영을 승인했다.

- 업무 화면의 전체 폭 원칙과 포털 읽기 폭을 구분한다. 포털은 약1100px 표/700px 설명을 기준으로 반응형 배치한다.
- 원제목 의료실비 변천사 / 암주요치료비 변천사 / 간병보험 변천사를 유지한다.
- 원문 내용과 비교표 행·열 유지. 간병은 3유형, 실손·암은 5세대이다.
- 모바일에서는 두 항목 선택 비교와 전체표 가로 이동을 제공한다. 원문 셀을 복제해 내용 차이를 방지한다.
- 다른 보험사 자료 표지를 변천사 대표 이미지로 사용하지 않는다. 각 내용에 맞는 전용 편집 일러스트를 쓴다. 보장 수치·상승 효과·보험사 로고를 표지에 만들지 않는다.
- 기획자: 제목/원문 및 모바일 비교 연결. 디자이너: 읽기폭/타이포/반응형 CSS. 코이사: 전용이미지 제작, 통합검수, PR·배포.
- 기존 개인자료 접근권한·소유자 게이트·로그인 전 화면은 변경하지 않는다.
