# 보험워크 공개자료실의 보험포털 전환 방향

- 결정일: 2026-09-01
- 상태: 방향 확정, 구현 보류
- 대상: 보험워크 자료실·공개자료실

## 결정

보험워크의 공개자료실은 파일을 그대로 나열하거나 공유하는 자료실보다 **보험정보 포털**에 가까운 서비스로 전환한다.

대표가 보험워크 자료실에 PDF, 이미지, 엑셀, 소식지, 교육자료 등을 자유롭게 넣으면 코상무가 원자료를 분석한다. 분석한 결과는 원본 파일 단위로 공개하지 않고, 보험 주제별 지식 페이지를 새로 만들거나 기존 페이지를 보완하는 데 사용한다.

현재는 방향만 저장하고 실제 화면·자동화·DB 작업은 다음 작업 시점에 별도로 설계하고 구현한다.

## 세 영역

1. **보험워크 자료실**
   - 원본 자료 투입과 내부 보관
   - 회사, 자료유형, 기준일, 심의·배포 제한 등 원자료 정보 유지
   - 원본은 공개 여부와 무관하게 근거 자료로 보존

2. **포털 제작·검수함**
   - 원문 추출, 주제 분류, 기존 글과 중복 비교
   - 새 글과 수정 글 초안 관리
   - 최신성, 출처, 심의기간, 고객 공개 가능 여부 검수
   - 근거 부족·구자료·고객 배포 금지 자료는 공개하지 않고 내부 검수 상태 유지

3. **공개 보험포털**
   - 일반 사용자가 이해하기 쉬운 주제 중심 보험정보
   - 검수된 내용만 공개
   - 출처, 사실 확인일, 마지막 업데이트 날짜와 변경 이력 표시
   - 고객 공유 가능한 페이지와 내부 전용 정보를 명확히 분리

## 콘텐츠 구성 원칙

- 파일 수를 늘리는 구조가 아니라 보험 지식 페이지의 정확도와 범위를 성장시키는 구조로 만든다.
- 회사별 자료를 회사별 글로 단순 복제하지 않는다. 공통 주제 페이지에 근거를 합치고 회사·상품 비교가 필요한 부분만 별도 구성한다.
- 원자료의 문구를 그대로 복사하지 않고 사용자 관점의 설명, 표, 체크리스트, 관련 용어와 연결 구조로 재구성한다.
- 오래된 통계와 광고 문구는 원출처와 현재 유효성을 다시 확인한다.
- 심의가 만료됐거나 고객 배포가 금지된 자료는 공개 페이지의 직접 근거로 사용하지 않는다.
- 상품 내용은 판매 여부, 기준월, 심의 상태를 확인한 경우에만 확정 정보로 표시한다.
- 보험 도메인 문구나 의료·법률 효과를 근거 없이 창작하지 않는다.

- 질병·치료
- 간병·노후
- 사망·상해
- 어린이·가족
- 보험금 청구
- 회사·상품
- 보험제도·개정
- 최근 업데이트

하위 콘텐츠 예시는 암, 뇌·심장, 간병, 사망보장, 후유장해, 골절·화상, 생애 상황별 보장 준비, 보험 용어, 상담 전 체크리스트 등이다.

## 원자료 처리 예시

`솔루션북_메리츠화재.pdf` 같은 자료는 PDF 한 건을 공개자료실에 그대로 배포하는 용도로 보지 않는다. 사망보장, 후유장해, 골절·화상 등 여러 주제 페이지의 내부 참고 원료로 사용한다. 이후 다른 보험사 자료와 공공기관 자료가 들어오면 동일 주제 페이지를 새로 중복 생성하지 않고 보완한다.

원본은 이미지형 63페이지 자료이며 화면에서 확인한 광고심의 유효기간이 2025년 1월에 종료됐다. 따라서 현시점 고객 공개 자료로 사용하지 않고 내부 참고 자료로만 취급한다.
