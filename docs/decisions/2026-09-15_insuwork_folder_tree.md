# 자료 폴더트리와 접이식 사이드메뉴

- 사이드메뉴는 화면 이동, 자료 내부 트리는 업무노트·자료실·메모 및 하위 폴더 탐색을 담당한다. 자료 상단의 중복 분류 탭은 트리로 대체한다.
- 사이드메뉴 상단에서 접으면 아이콘/약칭과 메뉴 이름 툴팁을 제공한다. 접기 상태는 브라우저에 기억하며 입력 화면 전체를 다시 그리지 않는다.
- 자료 폴더트리도 별도로 접을 수 있다. 모바일에서는 상단 영역으로 배치한다.
- 파일·노트·메모는 목록/카드에서, 폴더는 트리에서 드래그해 목적지 폴더 또는 분류 루트로 이동한다. 자기 자신/하위 폴더 이동은 차단한다.
- 이동은 본인 소유 항목의 parent_id와 분류 메타데이터만 변경한다. 원본·본문·첨부·ID·저장 경로는 유지한다. 하위 항목의 분류는 최상위 부모를 따라가므로 폴더 이동에 하위 파일 일괄 업데이트가 필요 없다.
- 보험이슈와 고객 카드 첨부는 이 트리로 합치지 않는다. 이번 UI는 단일 항목/폴더 드래그 이동이며 다중 선택·키보드 잘라내기·이동 취소는 포함하지 않는다.
