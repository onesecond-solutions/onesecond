# 보험워크 보장분석 파일 불러오기 연결 및 진행 안내 — 2026-09-12

## 요청과 확인한 문제
- 요약 이미지(구분/보장내용/추천금액/상태/가입금액)를 불러올 때 가짜 보험사·상품 열, 중복 대분류, 잘못 연결된 금액이 발생했다.
- 이전 동의어 사전의 치매·간병 분류가 사용자가 삭제·저장한 뒤에도 다시 생성됐다. 간호·간병통합서비스가 기존 간병인 대신 간병으로 추가됐다.
- 괄호 전체를 제거한 매칭 키 때문에 대인/대물 벌금과 지급률 조건이 다른 담보가 같은 행을 덮어쓸 수 있었다.

## 반영 기준
- 사용자가 저장한 분류와 담보명을 우선 유지한다. 간병/치매간병/치매·간병의 수입 항목은 기존 간병인·치매·장기요양에 연결한다.
- 괄호 속 보장 조건을 유지하고, 명시적 동의어만 매칭한다. 간병인 지원과 사용은 별개다. 원본에 지급일수 등이 없으면 임의로 특정 조건의 행에 넣지 않고 같은 대분류 안에 원본 조건을 보존한 행으로 추가한다.
- 요약표의 보험사/상품명 같은 단일 빈 머리글은 실제 상품으로 만들지 않는다. 가입금액을 합계금액에 유지한다. 추천금액을 가입금액으로 대체하지 않는다. 여러 익명 상품 열은 금액 유실 없이 보존한다.
- 분석 시작부터 연결·저장 종료까지 보장분석 중 모달을 표시한다. 전체 화면 위에서도 보이며 중복 불러오기를 차단한다. 실패 시 모달을 닫고 오류를 알리며 기존 편집본을 유지한다.

## 범위와 확인
- 기존 임태성 게이트 유지. DB/권한/추출 서비스 변경 없음.
- 이미 저장된 과거 잘못된 결과는 자동 삭제하지 않는다. 이번 변경은 앞으로의 파일 연결 규칙이며, 과거 결과는 사용자 확인 후 정리해야 한다.
- 조건 구분, 기존 분류 우선, 요약표 상품 처리, 진행·실패·중복 실행 회귀 테스트 추가. 기존 운전자 테스트의 VM 배열 비교만 호스트 배열로 변환했다.
