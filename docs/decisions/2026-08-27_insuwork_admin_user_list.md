# 보험워크 관리자 사용자 목록

- 확정일: 2026-08-27
- 확정자: 임태성 대표
- 적용 대상: `/insuwork/`

## 확정 사항

1. 보험워크 우측 상단 계정 메뉴에 `사용자 관리` 입구를 둔다.
2. 입구와 `?view=insuwork&section=admin-users` 직접 접근은 로그인 이메일이 정확히 `bylts@naver.com`인 계정에서만 허용한다.
3. 첫 버전은 운영 DB를 변경하지 않는 읽기 전용 사용자 목록으로 제공한다.
4. 목록에는 이름, 닉네임, 이메일, 회사명, 휴대전화, 가입일, 최근 로그인, 이용 상태를 표시한다.
5. 이용약관과 개인정보 수집·이용 동의는 가입 시 필수이므로 목록 기본 열에서는 제외한다. 동의 일시와 버전 기록은 계정 메타데이터에 계속 보존한다.
6. 전체 사용자 수, 오늘 가입자 수, 검색 결과 수와 이름·닉네임·이메일·회사명·휴대전화 검색, 이용 상태 필터를 제공한다.
7. 사용자 수정, 정지, 삭제, 권한 변경 기능은 이번 범위에 포함하지 않는다.

## 보안 경계

- 프런트엔드는 계정 메뉴 노출과 SPA 섹션 진입을 각각 검사한다.
- 사용자 목록 조회는 기존 `public.users` 읽기 권한과 RLS를 그대로 사용한다.
- 별도 DDL, RLS 변경, 운영 데이터 쓰기는 수행하지 않는다.
