# 롯데손해보험 자료 전용 보장분석 — 2026-09-22

대표 요청: 기본형은 모든 로그인 사용자가 사용하는 공통 양식으로 유지한다. 임태성 게이트에서 롯데손해보험 자료가 들어오면 별도 보장분석표를 열고, 대표가 라이브 결과를 검토한다.

- 보험워크 전용 변경. 기본형 → 롯데손해보험 → KB손해보험 → 뱅크샐러드 → 카카오페이 순서. 표 바로 위 기존 브라우저형 탭을 재사용하며 중첩 패널을 추가하지 않는다.
- 대표 제공 자료는 문서상 인스밸리 가로형 보장분석 양식이다. 파일명이나 가입 보험사명이 아닌 문서 구조로 인식한다. 롯데손해보험은 화면상 자료 출처명이며 실제 상품의 보험사명은 원문 그대로 보존한다.
- 임태성만 전용 파서/자동 탭 이동을 사용한다. 일반 사용자의 기본형·공통 양식·권한은 유지한다. 롯데 작업표는 기존 비공개 payload의 coverage_analysis_tab=lotte로 분리한다. DB/RLS 변경 없음.
- 기획 검토: 기존 담보 행 × 보험사·상품 열 유지. 상품 머리글에 보장기간·납입기간·보험료 원문 확인 표시, 담보 아래 접근 가능한 원문 펼치기를 제공한다.
- 상품별보장내용 상세 페이지에서 좌우 두 열의 담보명/금액/원문 분류를 추출한다. 앞쪽 요약·적정금액·평가를 담보로 재수입하지 않는다. 단위는 만원. 긴 이름이나 잘린 이름을 임의 완성하지 않는다.
- 최초 검토 단계에서는 원문 담보별 행을 유지한다. 표시명을 새 기본형 사전에 자동 확정하거나 서로 다른 상품의 유사 담보를 합치지 않는다. 대표의 검토 후 연결을 보완한다.
- 조건 없는 단일 원문행은 원문 금액을 합계열에 표시한다. 조건 있는 행은 합계 공백과 조건 확인 표시. 묶음/세부 동시 존재는 중복 확인으로 표시하며 원문 행 자체는 보존한다. 약관상 지급액을 확정하는 기능이 아니다.
- 가져오기 전에 기존 탭의 미저장 작업을 보존하고 인식 후 롯데 탭으로 전환한다. 실패하면 원래 탭으로 복귀한다. 여러 양식 혼합 선택은 분리 가져오기를 안내한다. 같은 계약 재수입은 중복 누적하지 않고 새 상세로 교체한다. 다른 고객 자료의 혼합은 차단한다.
- 고객 원본 PDF·추출 JSON·개인정보는 Git에 저장하지 않는다. 테스트는 익명 가상자료를 사용하고 실물은 로컬에서 검증한다.
