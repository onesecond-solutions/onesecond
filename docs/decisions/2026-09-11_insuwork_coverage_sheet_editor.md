# 보험워크 보장분석 엑셀 편집기

## 확정 사항

- 사이드메뉴의 `보장분석·보험비교` 다음에 `보장분석 엑셀`을 별도 메뉴로 둔다.
- 메뉴와 직접 URL은 임태성 user_id `98c5f4f9-10c1-4ee1-a656-5c2ca63239fd` 게이트에서만 허용한다.
- 사용자는 엑셀이 설치되지 않은 PC에서도 브라우저에서 셀 값, 병합, 서식, 행과 열을 편집한다.
- 기본표는 대표가 제공한 `보장분석 기본표.xlsx`의 시트 구조, 병합, 너비, 높이, 색상을 따른다.
- 정적 배포본에는 고객명, 보험회사·상품, 보험료, 보장금액을 넣지 않는다. 개인정보가 제거된 빈 기본표만 제공한다.
- 실제 작업본은 `insuwork_items`의 본인 전용 비공개 설정 항목 `coverage_sheet_workbook`에 XLSX 원본 형태로 저장한다.
- 편집 중에는 브라우저 로컬 임시 저장을 사용하고, `작업본 저장`을 누르면 서버 비공개 작업본을 갱신한다.
- `파일 불러오기`로 다른 XLSX를 열 수 있으며, `XLSX 내려받기`로 다시 엑셀 파일을 저장한다.

## 기능 경계

- 이 화면은 자유 편집용이며 고객카드의 자동 보장분석 원장과 분리한다.
- 고객별 자동 인식과 비교 저장은 기존 `보장분석·보험비교`에서 계속 수행한다.
- 엑셀 매크로, 피벗, 외부 연결과 Excel 전용 고급 기능은 브라우저 편집 범위에 포함하지 않는다.
