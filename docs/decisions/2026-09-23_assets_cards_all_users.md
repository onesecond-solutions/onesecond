# 2026-09-23 자료 카드 전체 사용자 개방

대표 지시: “전체 개방하자”. 직전 배포한 자료 카드와 ⋮ 관리 메뉴를 전체 로그인 사용자에게 개방한다. 이전 임태성 전용 노출 규칙을 이 기능에 한해 대체한다.

- 범위: 보험워크 자료 메뉴 전체/업무노트/자료실/메모, 하위 폴더 및 목록 보기의 관리 메뉴. PC·모바일 공통.
- 로그인한 사용자는 각자의 자료를 카드로 보고 이름 변경, 폴더 이동, 새 폴더 생성 및 기존 유형별 관리 기능을 사용한다.
- 모든 변경의 본인 소유자 조건, 미삭제 조건, 이동 분류 및 순환 방지를 유지한다. 다른 사용자의 자료를 공개하거나 권한을 늘리지 않는다.
- DB 스키마·RLS·인증 변경 없음. 다른 대표 전용 기능의 게이트는 변경하지 않는다.
- 일반 사용자 본인 자료 허용/타인 자료 거부, 비로그인 거부, 일반 사용자 변경 요청의 소유자 조건을 회귀 검사한다.
