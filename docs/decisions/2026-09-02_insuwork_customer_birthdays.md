# 보험워크 고객 생일 일정 표시

- 계약관리 고객의 생년월일을 기준으로 매년 생일 일정을 자동 계산한다.
- 생일은 별도 저장 행을 만들지 않는 읽기 전용 반복 일정이며, 2월 29일은 윤년이 아닌 해에 2월 말일로 표시한다.
- 캘린더 일·주·월·일정 보기에서 생일 전용 색상으로 다른 일정과 구분한다.
- 월 보기에서 같은 날 생일이 여러 명이면 `생일 N명`으로 묶고, 일 보기에서 전체 고객을 확인한다.
- 일정 목록에는 생일 열을 별도로 두며, 생일을 누르면 해당 고객의 계약관리 상세로 이동한다.
- 홈의 선택 날짜 할 일에는 `생일` 영역을 추가하고 동일한 색상과 이동 방식을 사용한다.
