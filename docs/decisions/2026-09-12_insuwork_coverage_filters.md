# 보험워크 담보현황 필터

- 상단 `+ 담보` 및 `개수 보기`를 `담보현황` 버튼으로 대체한다.
- 누르면 도구 모음 아래 `전체현황`과 현재 원장의 대분류 버튼을 표시한다. 빈 대분류는 `미분류`로 표시한다.
- 대분류 선택 시 해당 행만 보여준다. 전체현황 선택 또는 담보현황 접기 시 전체 행을 표시한다.
- 필터 상태는 화면 전용이다. 기본 양식·고객 저장은 필터 밖의 행도 모두 보존한다.
- 기존 행의 ＋ 버튼으로 담보를 추가한다. 필터된 표의 행 편집·추가·삭제는 원장의 원래 행 위치를 사용한다.
- 일반 화면과 전체 화면에서 동일하게 동작한다.

## 다중 선택

- 대분류 버튼은 복수 선택한다. 암·뇌·심장을 누르면 세 분류를 기존 원장 순서대로 함께 표시한다.
- 선택 버튼은 금색이며 다시 누르면 해제한다. 전체현황 또는 마지막 선택 해제 시 전체 행을 표시한다.
