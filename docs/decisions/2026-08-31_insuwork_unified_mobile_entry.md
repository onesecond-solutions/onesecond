# 보험워크 공용 주소와 모바일 진입 통일

- 대표 승인: “그래, 그렇게 통일시켜서 수정해줘.”
- 범위: onesecond 보험워크 전용. 데이폴더 두 제품은 변경하지 않는다.
- 안내/신규 설치 주소는 `/insuwork/`. 비로그인은 공개 랜딩, 로그인한 휴대폰은 `/insuwork/m/` 전용 화면으로 연결한다. PC 창을 좁혔다는 이유만으로 모바일 이동하지 않는다.
- 휴대폰 UA 또는 모바일 UA 정보, 작은 화면+터치+coarse pointer를 사용한다. 태블릿을 무조건 휴대폰으로 취급하지 않는다.
- 삭제된 PC 보기 메뉴와 referrer 기반 PC 예외는 복구하지 않는다.
- 기존 모바일 홈/일정/고객/상담/자료/검색을 보존한다. 보조 메뉴는 section.html에서 기존 콘텐츠/권한 검사를 재사용하면서 모바일 헤더/하단 메뉴를 사용한다.
- 날짜/검색/상세 id를 이동 URL에 보존한다. 오늘 이외 홈 날짜는 모바일 일정에서 그 날짜부터 보여준다. 모바일 일정은 기존 목록 방식이며 PC 월간 그리드를 복제하지 않는다.
- 신규 설치는 공통 manifest를 사용한다. 기존 모바일 manifest는 기존 id를 명시해 식별자를 유지하고 시작 주소/범위를 공용 주소로 설정한다.
- 인증 비밀/권한/RLS/DB 스키마와 운영 데이터는 변경하지 않는다.
- 검증: `node --test scripts/insuwork_mobile_routing.test.cjs scripts/insuwork_loading.test.cjs` (라우팅 8개 + 기존 로딩 회귀 6개), 변경 JS 문법 검사, 브라우저 렌더 및 배포 후 실제 이동 확인.
