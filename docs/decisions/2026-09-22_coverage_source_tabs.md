- 이번에는 동일한 현재 기본 양식을 사용하는 탭 구분만 구현한다. 회사별 담보·연결 사전·분석 규칙은 대표가 정리한 후 후속 지시로 확정한다.
- 기존 작업표는 기본형에 보존하고 처음 진입 시 기본형을 선택한다. 새 세 탭은 현재 기본 양식의 행 식별자와 구성을 유지하며 고객 정보와 입력 금액을 복제하지 않는다.
- 탭 이동 시 작성 중인 표·분류 필터·스크롤을 유지한다. 작업표 저장·초기화는 해당 탭에만 적용한다. 새로고침 이후 보존하려면 기존 작업표 저장을 사용한다.
- 기본 양식 관리와 고객별 최종 원장은 기존 공통 기능이다. 이번에는 출처별 별도 기본 양식이나 고객 원장 4개를 만들지 않는다.
- 대표 게이트에서 먼저 노출한다. 일반 로그인 사용자는 기존 보장분석 화면을 유지한다. 기존 비공개 메모 payload에 작업표 탭 식별자를 저장하며 이전 식별자 없는 작업표는 기본형이다. DB 스키마/RLS/서버 함수 변경과 운영 데이터 일괄 변경은 없다.
