# KB 손해보험 보장분석 PDF 우선 처리

- 대표 승인: KB 전산 보장분석 PDF를 최우선으로 읽고, 회사별 상세 담보명을 대표 기본 양식에 연결한다. 다른 보험사 양식은 실제 원본을 검증하며 추가한다.
- KB A4 상세표의 회사 담보명/신정원 담보명/가입금액을 위치로 분리한다. 계약별 연속 페이지를 연결하고 상세 행 번호로 중복을 제거한다. 요약/추천/진단 페이지는 금액 원장에 넣지 않는다.
- 카티/표적/세기조절/양성자/중입자는 독립 담보로 매칭한다. 원문 조건, 신정원 명칭, 페이지와 행 번호를 보존한다. 미확정 담보는 원문으로 남긴다.
- 동일 계약은 KB 상세를 우선하며, 이후 마이데이터 금액은 덮어쓰지 않는다. 기본 양식 자체는 수정하지 않는다.
- 구조화 추출 실패 시 무조건 숫자 첫 항목을 가입금액으로 넣던 PDF 예비 처리를 제거한다. 인식한 KB 상세표 형식이 다르면 기존 작업표를 유지하며 오류를 알린다.
- 이미 잘못 저장된 작업표는 자동 수정하지 않는다. 원본 재분석이 필요하다. 실제 고객 자료/암호는 저장소에 넣지 않는다.

## 실손 및 기존 오류표 보정
- KB 근거가 있는 상해+질병 통합 입원/통원 담보는 기본 양식의 상해·질병 각각에 같은 한도로 표시하고 동일 한도임을 담보명 설명에 명시한다.
- 과거 숫자 제거식 PDF 파서가 만든 명백한 단위/상태 혼합 행은 legacyRejectedRows에 보관하고 표시 대상에서 제외한다. 기본 양식에서도 같은 보정을 적용해 초기화 때 재등장하지 않게 한다.
- 서로 다른 고객의 KB 상세 페이지는 하나로 분석하지 않는다.
- 작업표 저장 중 재호출을 차단하며 저장 완료 알림은 사용자 저장 동작에서 한 번만 표시한다. 자동 보존/내부 저장은 별도 팝업을 내지 않는다.

## 대표 확정 명칭 및 분류 (2026-09-13)
- 급성심근경색증/급성심근경색, 허혈심장질환/허혈성심장질환은 동의어로 연결한다. 진단과 수술은 구분한다.
- 특약명에 암주요치료비가 포함되면 `암 > 치료비3 > 암주요 치료비(급여, 비급여 포함)`으로 표시한다.
- 하이클래스 또는 비급여 암주요치료비는 위 일반 규칙보다 먼저 `암 > 치료비3 > 비급여 암주요 치료비`로 분류한다.
- 이는 보험워크의 대표 지정 분류 규칙이다. 약관의 보장 여부를 별도 판정하거나 지급조건을 제거하는 근거로 사용하지 않는다. 원래 회사 담보명과 세부조건은 sourceNames/sourceDetails에 보존한다.
- 저장된 기본 양식과 작업표도 불러올 때 명칭/분류를 정규화한다. 서로 다른 지급조건의 금액을 단순 합산하거나 삭제하지 않는다.
