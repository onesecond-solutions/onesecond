# 보험워크 채팅 스크롤 캡처

- 보험워크 `계산기 · 변환기`에 `스크롤 캡처` 카드를 둔다.
- 첫 화면에는 `채팅창 캡처 시작` 버튼을 둔다.
- 버튼을 누르면 이미 열려 있는 해피톡 또는 보맵플래너 탭으로 이동한다.
- 사용자가 채팅 영역을 위에서 아래로 드래그하며 범위를 정한다. 아래쪽 가장자리에 닿으면 해당 영역을 자동으로 스크롤하고, 마우스를 놓으면 한 장의 PNG로 합쳐 저장한다.
- 확장 프로그램은 `onesecond.solutions`, `counselor.happytalk.io`, `dplanner.bomapp.co.kr`에서만 작동한다.
- 이미지와 채팅 내용은 서버나 보험워크 DB로 전송하지 않고 사용자의 PC에만 저장한다.
- 새 기능 노출은 현행 게이트 정책에 따라 임태성 지정 user_id에 한정한다. 비인가 사용자가 `tool=capture`로 직접 진입하면 계산기로 되돌린다.
- 크롬 보안상 확장 프로그램 설치는 사용자가 압축을 풀고 `chrome://extensions`에서 직접 승인한다.
