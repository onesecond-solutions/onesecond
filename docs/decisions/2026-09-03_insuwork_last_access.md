# 보험워크 마지막 접속

- 사용자 관리의 '최근 로그인'은 '마지막 접속'으로 표시한다.
- 재로그인 여부와 무관하게 인증된 PC·모바일 화면 진입, 탭 복귀 시 기존 `touch_last_seen` RPC로 본인의 접속 시각을 기록한다.
- 화면이 보이는 동안 2분마다 갱신한다. 숨김·페이지 이탈·인증 해제 시 중단한다. 키보드/마우스 활동이나 정확한 종료 시각을 추적하는 기능은 아니다.
- 사용자 관리 목록은 기존 30초 조회 주기로 기록을 반영한다. 초 단위 실시간 접속이나 접속 이력 전체를 의미하지 않는다.
- 기존 `users.last_seen_at`은 구 원세컨드 화면에서도 기록하는 공용 값이다. 보험워크만의 접속 이력을 별도로 분리하지 않는다.
- 기존 본인 전용 RPC를 재사용하며 DDL, RLS, 권한 및 과거 접속 시각은 변경하지 않는다. 기록 실패는 작업을 막지 않고 다음 주기에 재시도한다.
