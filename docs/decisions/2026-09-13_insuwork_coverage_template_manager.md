# 보장분석 기본 양식 관리 분리

- 대표 확정: 작업표의 기본 양식 저장 버튼은 오조작 위험이 있으므로 제거한다. 페이지 제목 오른쪽에 대표 전용 `양식 관리 ⚙`를 두고, 그 안에서만 기본 양식을 편집·저장한다.
- 별도 편집기는 저장된 기본 양식을 복제한다. 현재 작업표를 편집 원본으로 사용하지 않는다. 분류·담보명·순서·행 추가/삭제를 편집하고, 고객 정보·상품·가입금액·원본 파일 정보는 양식 저장 대상에서 제외한다.
- `변경 내역 확인`에서 추가/삭제/수정/순서 변경을 표시한 뒤 `기본 양식 저장`을 제공한다. 검토하지 않은 초안은 저장할 수 없고, 저장 중 중복 클릭·닫기를 차단한다. 실패하면 검토한 초안을 유지한다.
- 기존 소유자 전용 이력 저장을 재사용한다. 이전 양식 확인 → 미리보기 → 별도 편집기로 불러오기 → 변경 내역 확인 → 저장 순서로 되돌린다. 이전의 양식·작업표 동시 복원은 폐기한다.
- 기본 양식의 저장 시각이 최신이어도 현재 작업표를 대체하지 않는다. `기본 양식으로 초기화`를 사용자가 명시적으로 누를 때만 작업표에 적용한다. 작업표 저장·고객별 저장은 유지한다.
- 현재 대표 게이트 및 DB 권한/스키마는 변경하지 않는다. 검증 과정에서 운영 기본 양식이나 고객 작업표를 저장하지 않는다.

검증: 별도 초안 격리, 금액·개인정보 제외, 변경 확인, 취소, 권한, 저장 실패/재시도, 중복 저장, 이력의 편집기 연결, 작업표 재조회 우선순위에 대한 자동 테스트. 크롬의 테스트 화면에서 편집 → 검토 → 저장 후 작업표 유지 확인.
