# 보장분석 초기화·작업표·기본 양식 저장 분리 — 2026-09-12

- 대표 지시: 기본 양식 저장은 대표의 폼 제작 기능이며, 초기화는 모든 이용자의 작업 흐름이어야 한다. 초기화를 위해 기본 양식 저장을 요구하지 않는다.
- 초기화는 저장된 기본 양식의 분류·담보·순서를 다시 가져오고 회사·상품, 가입금액, 원본 연결, 선택 상태를 비워 개인 작업표에 바로 적용·저장한다. 현재 가져오기에서 추가된 행은 기본 양식에 저장된 행이 아니라면 초기화 결과에 남기지 않는다.
- 파일 불러오기 자동 저장과 새 작업표 저장 버튼은 개인 작업표 전용 비공개 레코드를 사용한다. 기존 기본 양식 레코드를 덮어쓰지 않는다. 실패 시 오류와 재저장 경로를 표시한다.
- 기본 양식 저장 버튼은 canEditCoverageTemplate에서 대표만 표시·저장한다. 고객 저장은 기존 고객 레코드 경로를 유지한다.
- 기존 레코드를 일괄 변경하지 않는다. 첫 진입은 기존 양식으로 시작하며, 작업표를 저장한 뒤에는 별도 작업표에서 재개한다. 대표가 더 최근의 기본 양식을 저장했다면 그 양식에서 재개한다.
- 현재 기능 공개 게이트와 DB/RLS를 확장하지 않는다. 일반 이용자 공개 자체는 별도 범위이며, 이번 변경은 초기화·작업표 저장을 기본 양식 수정 권한에서 분리하는 것이다.
