# 보험워크 엑셀 비밀번호 구분 — 대표 확정

- 뱅크샐러드의 비밀번호는 해당 고객의 생년월일 6자리(YYMMDD)다. 공통 고정값이 아니다.
- 보맵의 비밀번호는 파일을 내려받은 사용자 본인의 사번이다. 고객 생년월일로 해석하지 않는다. 실제 보맵 파일은 아직 제공받지 않았다.
- 암호화된 파일만 입력을 요청한다. 파일명의 뱅크샐러드/banksalad, 보맵/bomapp 표기로 안내를 구분하며, 알 수 없는 파일명은 두 기준을 함께 안내하고 비밀번호로 생년월일을 추정하지 않는다.
- 뱅크샐러드 잠금 해제에 성공한 생년월일만 임시 전달한다. 문서의 전체 생년월일과 대조하며, 문서에 출생연도가 없으면 4자리 출생연도를 추가로 확인한다. 취소하면 날짜를 비워 직접 입력할 수 있다. 19xx/20xx를 임의로 선택하지 않는다.
- 비밀번호/사번은 저장·로그·고객 데이터·원본 메타데이터에 넣지 않는다. 확인된 전체 생년월일만 기존 고객 정보와 보험나이 계산에 연결한다.
- 기존 고객 정보 추출 결정의 '비밀번호로 생년월일 추정 금지'에 대한 명시적 예외는 위 뱅크샐러드 입력 흐름뿐이다. OCR이 문서의 암호 문구를 날짜로 해석하는 것은 계속 금지한다.
- 테스트: 공급자별 안내, 숫자로 된 사번의 날짜 오인 방지, 암호 없는 파일, 복호화 실패, 문서 날짜 대조, 출생연도 취소/불일치.
