# 2026-09-14 기본 양식 분류·순서 보존
- 기본 양식 편집 화면과 기본 양식으로 초기화한 작업표는 동일한 담보명·대분류·중분류·순서를 유지한다. 암 치료비3를 담보명 기반으로 재분류하지 않는다.
- 기본 양식 복제 및 해당 작업표에는 preserveTemplateLayout을 저장한다. 재조회·고객 연결·파일 병합 후에도 사용자 구조를 보존한다.
- 외부 파일 원본의 자동 분류는 유지하되 기본표와 일치한 행은 값과 출처만 병합한다. 없는 담보는 해당 분류 뒤에 추가한다.
- 운영 기본 양식 및 기존 고객 데이터를 일괄 변경하지 않는다. 기존 작업표는 자동 초기화하지 않으며 사용자의 명시적 초기화로 저장된 양식을 다시 적용한다.
