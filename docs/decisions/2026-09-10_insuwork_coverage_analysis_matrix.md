# 보험워크 고객 보장분석 편집 원장

## 확정 범위

- 계약관리와 상담관리의 고객 상세 카드에서 같은 고객별 보장분석 원장을 사용한다.
- 현재 기능 공개 범위는 임태성 user_id `98c5f4f9-10c1-4ee1-a656-5c2ca63239fd` 게이트다. 추후 다른 사용자에게 고객별 보장분석 기능을 개방할 수 있지만, 기본 양식의 편집·저장 권한은 계속 임태성에게만 둔다.
- 엑셀 업로드, 기존 고객·상담 첨부 PDF 불러오기, 직접 입력을 하나의 편집 화면에서 지원한다.
- 원본 엑셀·PDF는 삭제하거나 덮어쓰지 않고 보장분석 원장과 연결해 보존한다.

## 독립 작업 화면

- 보험워크 사이드메뉴의 `자료` 바로 아래에 `보장분석` 메뉴를 둔다. 현재는 임태성 전용이며, 다른 사용자에게 개방하더라도 권한에 따라 화면과 저장 동작을 분리한다.
- 보험워크 공통 레이아웃 안에서 엑셀 파일을 올리면 편집 가능한 전체 보장분석 표를 바로 펼쳐 보여준다.
- 엑셀을 아직 올리지 않은 첫 진입에도 실손·암·뇌·심장·수술비·배상책임·운전자 빈 표를 표시해 바로 입력할 수 있게 한다. 엑셀을 불러오면 이 빈 표를 원본 데이터로 대체한다.
- 초기 빈 표가 먼저 렌더되더라도 비동기로 불러온 저장 원장을 무시하지 않고 즉시 교체해, 재진입 시 마지막 저장 양식을 복원한다.
- 독립 보장분석 페이지에서 편집한 표는 `기본 양식`으로 저장한다. 고객별 원장이 없는 계약관리·상담관리 카드는 이 양식을 복제해 시작하며, 고객별 수정·저장은 기본 양식을 덮어쓰지 않는다.
- 독립 화면에서 만든 작업과 원본 엑셀은 개인 비공개 자료로 저장하며 일반 자료 목록에는 중복 노출하지 않는다.

## 권한과 저장 경로

- 기본 양식의 소유자·편집자·저장자는 임태성 user_id `98c5f4f9-10c1-4ee1-a656-5c2ca63239fd`로 고정한다.
- 다른 사용자에게 보장분석 메뉴를 개방해도 `기본 양식 저장` 버튼과 기본 양식 변경 API는 노출하거나 허용하지 않는다. 화면 숨김만으로 끝내지 않고 저장 경로에서도 권한을 검사한다.
- 일반 사용자는 임태성이 저장한 기본 양식을 읽기 전용 원본으로 사용한다. 기본 양식을 직접 수정하지 않고 고객별 작업을 시작할 때 복제본을 만든다.
- 일반 사용자가 보장분석을 저장할 때는 먼저 대상 고객을 선택하거나 해당 고객 카드로 이동해야 한다. 저장 결과는 반드시 그 고객의 계약관리·상담관리 공용 보장분석 원장에 연결한다.
- 고객이 정해지지 않은 일반 사용자의 임시 표를 기본 양식이나 공용 작업으로 저장하지 않는다. 고객 선택 전에는 저장을 차단하고 고객 카드 선택 안내를 제공한다.
- 고객별 원장은 작성 사용자의 기존 데이터 접근 범위와 소유권 정책을 따르며, 다른 고객 원장이나 임태성 기본 양식을 덮어쓰지 않는다.

## 편집 원칙

- 보험사·상품 열은 금액이 비었다는 이유로 자동 제외하지 않는다. 빈 셀은 미가입 확정값이 아니라 원자료의 빈 값으로 유지한다.
- 보험사·상품 숨김은 사용자 선택으로만 처리하며 숨긴 자료도 원장에 보존한다.
- 사용자는 보험사·상품 열과 담보 행을 추가하고 대분류·중분류·담보명·합계금액·상품별 가입금액 셀을 직접 수정할 수 있다.
- 화면에서는 연속된 같은 대분류·중분류를 엑셀처럼 세로 병합해 표시한다. 중분류가 없는 원본은 임의 분류를 생성하지 않고 사용자가 입력할 수 있게 둔다.
- 암 대분류는 담보명에 따라 `진단비`, `치료비1`, `치료비2`, `치료비3` 순서로 중분류를 구성한다. 기존에 저장된 `치료비 1` 형식도 공백 없는 표기로 통일한다.
- 암 진단비의 `고액암` 담보는 표에서 제외한다. 치료비1은 `항암방사선약물치료비`, `암수술비`, 치료비2는 로봇암수술비·표적항암약물치료비·양성자·세기조절·카티·중입자 방사선 치료비, 치료비3은 암주요치료비와 비급여 암주요치료비로 구성한다.
- 실손 대분류는 중분류를 사용하지 않고 대분류 셀이 중분류 열까지 가로 병합된다.
- 대분류는 `실손`, `암`, `뇌`, `심장`, `수술비`, `배상책임`, `운전자` 순서로 정렬하며, 원본의 더 구체적인 명칭은 그대로 보존한다.
- 선택 체크박스는 개별 담보 행이 아니라 병합된 대분류마다 하나만 제공하고, 체크하면 해당 대분류의 모든 담보를 함께 선택한다.
- 표는 행과 보험사·상품 열을 드래그해 순서를 바꿀 수 있으며, 대분류·중분류·담보명은 셀에서 직접 수정한다.
- 대분류·중분류·담보명·합계금액 열은 실제 텍스트 길이에 맞춰 폭을 계산하고, 보험사·상품 열은 비교가 흐트러지지 않도록 동일한 고정 폭을 유지한다.
- 금액 기준 열은 추천금액이 아니라 원본의 가입금액·총가입금액·합계금액을 읽어 `합계금액`으로 표시한다.
- 충분·부족·없음 개수는 기본으로 숨기고 필요할 때만 펼친다.
- 선택 담보, 선택 담보가 속한 섹션, 전체 담보를 복사할 수 있고 카카오 발송 문안으로 넘길 수 있다.
- `선택 화면 복사`는 텍스트가 아니라 체크한 대분류만 대분류·중분류 병합과 보험사·상품 열을 유지한 PNG 표로 만들어 클립보드에 복사한다.

## PDF 인식

- 텍스트형 PDF는 브라우저에서 텍스트 위치를 읽어 편집 초안을 만든다.
- PDF 인식 결과는 확정값이 아니며 항상 검토가 필요한 초안으로 표시한다.
- 이미지로만 된 스캔 PDF가 표로 인식되지 않으면 오류를 숨기지 않고 OCR 또는 직접 입력이 필요하다고 안내한다.

## 저장

- 별도 운영 DB DDL 없이 기존 개인 소유 `insuwork_items`에 고객별 비공개 메모로 구조화 원장을 저장한다.
- 기본 양식은 `workspace_category='coverage_analysis'`, `coverage_analysis_workspace=true`, `coverage_analysis_template=true`로 구분하고 임태성 소유 레코드만 갱신한다.
- `legacy_payload.workspace_category='customer'`, `coverage_analysis_record=true`, `customer_id`로 고객과 연결한다.
- 새로 업로드한 원본은 기존 `myspace` 비공개 버킷에 원장 자식 파일로 저장한다.
