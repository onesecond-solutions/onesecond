# 실제 화면 기반 가이드와 빈 계정 시작 안내

대표 요청: 가상 HTML 시연을 실제 보험워크 캡처로 교체하고 디자이너와 화면을 개선한다. 자동 가이드는 고객·상담·자료가 없는 사용자에게 표시한다.

- 동일 제품 코드의 localhost 검증 화면에서 예시 데이터로 촬영한 12개 PNG를 사용한다. 운영 고객 자료는 촬영/저장/공개하지 않았다.
- 5개 메뉴 15단계, 공개 5단계 시연에 실제 화면 및 해당 위치 강조를 연결한다. 화면 크게 보기 제공.
- Navy/Gold, 큰 캡처, 하단 설명 및 재생 제어. PC/390px 팝업 시각 검수.
- 사용자 데이터 조회가 모두 성공한 후 고객·상담 존재 여부와 별도 본인 자료 존재 조회로 빈 계정을 판별한다. 설정 항목은 자료로 세지 않는다. 조회 실패·계정 변경 시 표시하지 않는다.
- 동일 탭 세션에서는 닫은 가이드를 반복하지 않는다. 기존 사용자 가이드는 지원에서 언제든 접근 가능하다.
- 자동 표시 연결은 PC 공용 셸 기준이며 전용 모바일 홈은 별도 구현이다. 안내 캡처는 PC 화면이다.

검증: JS 문법 및 diff 검사, 8가지 자동 팝업 판정 테스트, 실제 캡처·팝업·390px 반응형 확인. 이메일 변경은 별도 보류 상태이며 이번 변경에 포함하지 않는다.
