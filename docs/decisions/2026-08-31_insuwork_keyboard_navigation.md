# 보험워크 입력칸 Tab 이동

- 보험워크 전용 수정, onesecond 저장소. 고객·상담 등록의 정상 입력 순서와 캘린더 네이티브 날짜 입력은 유지한다.
- 가계부에서 투명한 달력의 연/월/일/버튼이 키보드 순서에 끼어든 문제를 수정했다. 숫자 날짜와 금액 사이 직접 Tab/Shift+Tab 이동, 달력 클릭 및 Alt+↓ 지원.
- 업로드 파일 제목 수정은 본문 편집기가 없는데도 Tab을 차단하던 문제였다. 본문이 실제 존재할 때만 제목→본문 단축 동작을 수행하며, 파일은 제목→공개 범위로 기본 이동한다.
- 검증: 실제 파일 수정 함수로 생성한 모의 폼에서 제목→공개 범위와 역방향 이동 확인. 가계부 실제 UI에서 A~F 순서/역순, 달력 호출/복귀 확인. 문법 검사 및 기존 가계부 수식·날짜 8개 테스트 통과.
- 기존 데이터·게이트 변경 없음. 운영 DB 저장 검증과 실물 휴대폰 키보드 검증은 하지 않았다.
