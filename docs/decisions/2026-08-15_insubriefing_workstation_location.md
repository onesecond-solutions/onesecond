# 보험브리핑 워크스테이션 배치와 `/insu/` 보존

- 확정일: 2026-08-15
- 확정자: 임태성 대표
- 상태: 현행

## 결정

1. `/insu/`는 개편 전 원세컨드 보험 화면을 그대로 보존한다.
2. 2026-08-14에 만든 개인 통합 업무 화면은 보험브리핑의 `워크스테이션` 메뉴로 제공한다.
3. 화면 주소는 `/insubriefing/workstation/`을 사용한다.
4. `업무공간`이라는 화면 명칭은 사용하지 않고 `워크스테이션`으로 통일한다.
5. 내부 안정 식별자인 `workspace_*` 테이블명과 기존 코드 식별자는 변경하지 않는다.
6. 기존 원세컨드 가입자는 재가입 없이 같은 인증 세션과 사용자 ID로 워크스테이션을 사용한다.
7. 최초 공개는 임태성 사용자 ID `98c5f4f9-10c1-4ee1-a656-5c2ca63239fd` 게이트로 제한한다.

## 구현 경계

- `/insu/`에서는 워크스테이션 화면을 자동으로 덮어쓰던 CSS·JS 연결만 제거한다.
- 통합 `workspace_items`, `workspace_customers`, `workspace_consultations`, `workspace_tasks` 데이터와 기존 이관 결과는 유지한다.
- 보험브리핑의 임시 로컬 로그인 표시는 폐기하고 실제 원세컨드 인증 토큰을 사용한다.
- 비로그인 사용자는 기존 로그인 화면으로 보내고 로그인 완료 후 `/insubriefing/workstation/`으로 안전하게 복귀시킨다.
- 전체 사용자 공개는 증분 이관과 교차 계정 RLS 검증 후 별도 승인으로 진행한다.
