# 2026-09-14 보장분석 전체 로그인 사용자 개방
- 대표 승인으로 보장분석·보험비교 메뉴, 계약·상담 고객 진입, 파일 인식을 로그인 사용자 전체에게 개방한다. 비로그인 및 익명 계정의 서버 호출은 거절한다.
- 기본 양식 관리·편집·저장은 임태성 전용으로 유지한다. 별도 보장분석 엑셀 메뉴 및 다른 실험 기능의 게이트는 유지한다.
- gemini-coverage-import는 Auth 서버로 토큰을 검증한다. GET은 임태성 기본 양식에서 담보명·분류·순서·숨김만 반환한다. 고객 정보·회사·상품·금액·첨부·원본 데이터는 반환하지 않는다.
- 공유 기본 양식은 읽기 전용이며 사용자별 작업표·최종 고객 원장은 기존 본인 소유 비공개 저장/RLS를 유지한다. 스키마와 RLS 변경 없음.
- 함수 배포는 production-functions 승인 경로로 진행한다.
