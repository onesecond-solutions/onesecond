- `briefing-latest.json`, `daily/YYYY-MM-DD.json`, `briefing-archive.json`에 날짜별 저장. 기존 content/library JSON 호환 유지. 일부 검색 실패나 빈 결과는 기존 정상 파일을 덮어쓰지 않는다.
- GitHub Actions 한국시간 05:17/06:17/07:17 예약. 오늘 게시 성공 확인 시 중복 실행 생략. 각 실행은 저장 후 Pages 빌드를 명시적으로 요청하고 라이브 JSON 타임스탬프까지 확인한다.
- GitHub 예약은 시간 보장이 없다. 오전 7시 전후 갱신 목표이며 절대 정시 실행을 약속하지 않는다. 사이트에는 실제 마지막 갱신 시각/오래된 날짜 표시. 실패는 Actions 실패 및 실행 요약에 기록한다.
- 검증: 수집 핵심 규칙 6개 + 기존 로딩 6개 + 모바일 라우팅 8개, 변경 JS 문법, 실제 CI 수집, PC/모바일 화면과 라이브 배포 확인. 실물 모바일 기기는 별도 확인 필요.
