# 보험워크 고객관리·상담관리 분리

- 확정일: 2026-08-28
- 적용 대상: 보험워크 PC·모바일 고객관리 및 상담관리

## 기준

1. 상담관리는 상담 기록 단위 목록이며, 상담 중인 잠재고객을 포함한다.
2. 고객관리는 `profile.customer_managed=true`, 고객상태가 고객관리 상태(청약완료·철회·실효·부활), 또는 기존 `sales_customers` 이관 고객인 경우만 표시한다.
3. 상담상태(예약·진행중·제안서발송·클로징·청약완료·보류·종결)는 상담 기록의 `channel`에 저장하며, 기존 고객상태를 덮어쓰지 않는다.
4. 상담상태가 `청약완료`가 될 때만 고객을 고객관리 대상으로 승격하고 고객상태를 `청약완료`로 저장한다.
5. 고객관리의 고객내용은 고객 메모만 표시하며, 최근 상담내용을 대신 표시하지 않는다.
6. 상담관리의 삭제는 상담 기록만 삭제하고 고객정보는 유지한다.

## 호환성

- 기존 원세컨드에서 이관된 `legacy_source=sales_customers` 고객은 고객상태 재확인 전에도 고객관리 목록에서 유지한다.
- DB DDL·RLS·운영 데이터 직접 수정 없이 기존 필드와 정책 안에서 적용한다.
