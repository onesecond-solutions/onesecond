# 청약일 반복 제거 및 기간 조회

- 청약일은 고객의 최초 청약 날짜에 한 번 표시한다. `care_auto`의 `:anniversary:` 자동 기념일은 더 생성하지 않고 기존 항목도 캘린더·홈에서 제외한다. DB 삭제 없이 사용자 직접 일정과 31·91·181·365일 케어·완료 기록을 보존한다.
- 신규 기간 조회 UI는 기존 운영 원칙에 따라 임태성 게이트에서 우선 제공한다. 계약관리는 최초 청약일·케어 예정일·생일, 상담관리는 등록일만 제공한다. 상담관리에는 케어 예정일을 넣지 않는다.
- 오늘, 최근 7일(오늘 포함), 이번 달, 지난달, 전체, 사용자 정의(시작일·종료일, 양끝 포함)를 제공한다. 이름·전화번호 및 상태 검색과 함께 적용한다.
- 케어 예정일은 캘린더와 같은 본인 소유 care_auto 일정 중 미완료 항목을 페이지 단위로 조회하며, 고객은 한 번만 표시한다. 로딩·실패 시 이전 대상 재사용을 금지한다.
- 카카오 전체선택은 렌더링된 일부 행이 아니라 조회 결과 전체다. 검색·상태·기간 변경 시 선택을 초기화하며 결과에서 제외된 대상은 발송 준비에서 제외한다. 기존 카카오 파일럿 게이트와 발송 준비 저장 방식은 유지한다. 실제 공급자 전송 기능을 추가하지 않는다.
- 운영 DB 일괄 변경, 메시지 발송, RLS 변경 없음.
