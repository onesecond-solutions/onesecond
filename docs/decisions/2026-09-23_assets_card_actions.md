# 2026-09-23 자료 카드와 더보기 메뉴

대표 요청: 자료 메뉴의 폴더와 이미지·PDF·텍스트 자료를 카드로 표시하고, 우측 ⋮에서 파일을 열지 않고 관리한다. 구현과 전용 도메인 배포까지 승인.

- 보험워크 전용 변경. 임태성 게이트에서 자료의 전체/업무노트/자료실/메모 및 하위 폴더에 적용한다. 일반 사용자 UI와 권한은 유지한다.
- 폴더는 큰 폴더 그림 없이 이름 중심의 낮은 카드, 자료는 제목과 미리보기 카드. 목록 보기에도 ⋮를 제공한다. 이미지/PDF는 기존 미리보기를 재사용하고 텍스트는 본문 일부를 표시한다.
- 카드 클릭은 열기, ⋮는 별도 메뉴. 이름 변경, 폴더 이동, 즐겨찾기, 정보, 휴지통을 제공한다. 자료 종류에 따라 내용/링크 수정, 다운로드, 주소 복사를 제공한다.
- 이동 창에서 같은 분류의 상위/하위 폴더를 탐색하고 새 폴더를 만든다. 자기 자신·하위 폴더·순환·타인 폴더로 이동할 수 없다. 원본 파일 경로와 하위 자료의 연결은 보존한다.
- 기존 개인 자료 저장 및 휴지통을 재사용한다. 비어 있지 않은 폴더 삭제 제한은 유지한다. 공유, 공개 복제, 폴더 ZIP 다운로드는 추가하지 않는다. DB 스키마·RLS 변경 없음.
- 이름 변경/이동은 소유자 조건과 미삭제 조건을 포함한 제한 PATCH. 새 폴더는 본인 비공개로 생성한다.
- 검증: 소유자 게이트, 이동 경로/순환 방지, 이름 변경의 필드 범위, 하위 연결 보존, 중복 제출 방지, 새 폴더 분류 보존, HTML 이스케이프 및 버튼 분리 자동 검사. 브라우저에서 PC/모바일 메뉴와 이동 창을 확인한다.
