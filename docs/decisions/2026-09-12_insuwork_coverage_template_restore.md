# 보장분석 기본 양식 이전 버전 복원 — 2026-09-12

- 대표 요청: 파일을 불러오기 전 기본 양식으로 복원한다.
- 기존 저장 시 보관된 history 레코드를 대표 전용 화면에서 조회·미리보기·복원할 수 있도록 연결한다. 현재 로그인 소유자와 기본 양식의 parent_id로 이력을 한정한다.
- 선택한 이력의 분류·담보·순서·값을 그대로 기본 양식과 작업표에 복원한다. 기존 저장 함수를 사용하므로 복원 전 기본 양식과 작업표도 각각 이력으로 보존된다. 새 권한·DB 스키마 변경 없음.
- 파일 전 시점의 정확한 복원이 요청되었으므로, 이후 추가한 행은 이번 복원본에 임의로 다시 넣지 않는다. 이후 버전 이력에는 보존된다.
