# 보장분석 작업 공간 확대

- 대표 요청: 계약관리·상담관리처럼 제목만 위에 두고, 표를 감싸는 중첩 카드 테두리·배경·패딩을 제거한다.
- 양식 관리·전체 화면 보기는 파일 불러오기 도구 줄 오른쪽에 배치한다. 전체 화면에서도 같은 도구 줄을 사용한다.
- 보장분석 페이지에 한해 main → 작업 영역 → 패널을 남은 높이를 채우는 flex 구조로 구성한다. 제목·도구·필터·저장 줄은 유지하고 표 영역만 스크롤한다.
- 화면 높이에서 고정값을 빼던 표 최대 높이를 해제한다. 하단 작업표 저장 줄은 사용 가능한 화면 맨 아래에 배치한다. 일반 화면 좌우 여백은 16px, 전체 화면은 12px로 줄인다.
- 고객 카드의 보장분석 패널과 다른 페이지 레이아웃에는 적용하지 않는다. 데이터·저장·기본 양식은 변경하지 않는다.

검증: 관련 회귀 테스트 22개 통과. 크롬 테스트 화면 1920×889와 1280×720에서 저장 줄 아래 여백 10px, 전체 화면 12px 확인. 작은 데스크톱 화면에서도 도구와 관리 버튼 같은 줄 배치 확인.
