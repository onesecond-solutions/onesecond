# 워크스테이션 개인 자료 식별 기준

> 확정일: 2026-08-15  
> 대표 확정: 개인 자료는 관리용 `owner_id`만으로 판정하지 않는다.

## 확정 원칙

- 기존 원세컨드 이식 자료는 원본에 기록된 작성 계정 이메일(`legacy_payload.owner_email`)이 해당 워크스테이션에 지정된 자료 출처 이메일과 같은 자료만 표시한다.
- 임태성 파일럿 워크스테이션의 기존 자료 출처 이메일은 `bylts@naver.com`이다.
- 관리자 계정 `bylts0428@gmail.com`으로 서버에 등록한 자료는 임태성 파일럿 워크스테이션에 표시하지 않는다.
- 임태성이 관리자였다는 이유로 같은 관리자 `owner_id`가 지정된 서버 공용 자료는 개인 자료로 가져오지 않는다.
- `myspace_folders`, `myspace_files`를 `owner_id`만으로 자동 포함하지 않는다. 관리자 계정으로 서버에 일괄 등록된 파일이 개인 자료에 섞일 수 있기 때문이다.
- 새 워크스테이션에서 작성·업로드한 자료는 `legacy_source IS NULL`이면서 현재 로그인 `owner_id`인 자료만 포함한다.
- 다른 사용자에게 확대할 때도 고정된 임태성 ID나 이메일을 사용하지 않고, 현재 인증 세션의 사용자 ID와 이메일을 사용한다.

## 검증 기준

- A 계정에서 B 계정의 개인 자료가 0건이어야 한다.
- 관리자 계정으로 서버에 올린 공용 자료가 개인 자료 목록에 나타나지 않아야 한다.
- 현재 로그인 계정이 직접 올린 기존 자료와 새 워크스테이션 자료는 보여야 한다.
