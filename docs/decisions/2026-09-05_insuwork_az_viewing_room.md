# 보험워크 에즈 시청방 접근 원칙

- 확정일: 2026-09-05
- 화면명: 에즈 시청방
- 위치: 보험워크 사이드메뉴 최하단의 별도 구획

## 접근 기준

- 메뉴는 명시적으로 허용된 인증 사용자에게만 렌더링한다.
- 허용되지 않은 사용자는 메뉴의 존재 자체를 볼 수 없다.
- `section=az-viewing-room` 직접 URL로 들어와도 동일한 허용목록을 검사하고 홈으로 돌린다.
- 사용자 관리 목록의 `에즈 시청방` 체크 한 개가 읽기·쓰기 권한을 함께 부여한다.
- 체크 해제 시 권한 레코드를 삭제하고 메뉴 및 직접 접근 권한을 함께 회수한다.
- 초기 허용 사용자는 임태성 대표 계정 `98c5f4f9-10c1-4ee1-a656-5c2ca63239fd` 한 명이며 관리 권한을 잃지 않도록 해당 체크는 고정한다.
- 이름이나 회사명만으로 팀원을 자동 허용하지 않는다.

## 화면 범위

- 팀 기능을 붙일 수 있는 독립 작업 공간으로 운영한다.
- 첫 기능으로 해피톡·보맵플래너용 `스크롤 캡처`와 설치 안내를 배치한다.
- 첫 화면에는 기능별 버튼만 표시하고, 버튼을 누르면 해당 기능 화면을 연다. 이후 기능도 같은 목록 구조에 추가한다.
- 열린 기능 상단에는 `에즈 시청방 | 기능명` 경로를 표시하고 `에즈 시청방`을 누르면 기능 목록으로 돌아간다.
- 스크롤 캡처는 `계산기 · 변환기`에서 제거하며 에즈 시청방 권한이 있는 사용자만 실행할 수 있다.
- 대표가 확정하지 않은 임의 기능이나 더미 콘텐츠는 추가하지 않는다.
