# 계약관리 → 보장분석 고객 작업 화면 연결

- 계약관리 목록과 고객 상세의 보장분석 버튼으로 넓은 보장분석 화면을 연다. 저장된 고객 표가 있으면 재분석 없이 그대로 열며, 처음에는 첨부 PDF 선택창을 표시한다.
- 자료 추가 분석에서 고객에게 연결된 PDF를 복수 선택한다. 최신 이미지/PDF 추출 파이프라인을 재사용하고 진행 안내를 유지한다. 분석 결과는 작업표로 저장하며 최종 고객 저장은 별도 버튼으로 한다.
- 고객명·생년월일·보험나이를 연결하고 저장 버튼에 고객 이름을 표시한다. 고객 저장 후 작업 화면을 유지한다.
- 고객 전환 전에 현재 작업표를 서버에 저장한다(기존 작업표 이력 보존 사용). 저장 실패 시 전환하지 않는다. 같은 세션에서 다른 고객으로 갔다 돌아오면 메모리의 수정본을 우선 복원한다.
- 기존 첨부 원본 ID를 재사용하고 새 업로드를 하지 않는다. 추가 분석 시 기존 원본 참조를 보존한다. 파일 조회는 소유자·삭제 여부·해당 고객 소속을 검증한다.
- 기존 대표 전용 게이트와 DB 스키마/RLS는 유지한다. 운영 고객 표는 검증 목적으로 저장하지 않는다.
