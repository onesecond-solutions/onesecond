# 보장분석 상단 정리와 원본 파일 보기

- 대표 확정: 중복 페이지 제목·설명·보장분석 작업표 안내 박스를 제거한다. 표 상단 한 줄에 보장분석·보험비교, 양식 관리, 전체 화면 보기를 배치한다.
- 고객 선택은 표 고객명 옆으로 이동한다. 등록 고객을 선택하면 이름·생년월일·보험나이를 연결하고, 직접 입력은 유지한다. 이름이나 생년월일을 직접 변경하면 기존 고객 연결을 해제하여 잘못된 고객에게 저장하지 않는다.
- 하단 `고객에게 저장`은 연결된 고객 ID로 저장한다. 미선택이면 선택 팝업을 연 뒤 저장한다. 삭제한 상단 select DOM에 의존하지 않는다.
- 원본 파일명은 상단에서 제거한다. 보험나이 바로 아래 `원본 파일 보기` 버튼을 원본 참조가 있을 때만 표시한다. 한 파일은 바로 열고, 여러 파일은 목록에서 고른다. 기존 단일 sourceItemId와 다중 source.files를 모두 지원한다.
- 원본은 기존 소유자 전용 저장소 파일만 접근한다. 고객별 표 저장에도 원본 참조를 유지한다. 이미지/PDF는 기존 미리보기, 기타 파일은 서명 URL로 열기/다운로드한다. 전체 화면에서 미리보기가 뒤로 가려지지 않도록 처리한다.
- 기본 양식 저장·초기화·데이터 권한은 변경하지 않는다. 테스트 데이터로 고객 선택·다중 원본 목록과 전체 화면을 검증하고 운영 고객 데이터는 저장하지 않는다.

검증: 관련 자동 테스트 34개 통과, 크롬 전체 화면에서 고객 선택 후 이름/생년월일 반영 및 원본 목록의 선택 대상 연결 확인.
