# 임태성 전용 간단 가계부

## 셀 편집 지출표
- **단일 입력표·고정비 단순화:** 선택한 달의 내역을 기본 표시하고 항목 아래 매월 반복으로 고정비를 등록한다. 반복 금액/날짜/납부 상태는 월별 override로 해당 월만 수정하며 원래 기준 금액은 유지한다. 반복 해제는 선택 월까지 유지하고 이후 중단, 전체 삭제는 모든 달 삭제를 명시한다. 원본 행 순서·수식 주소는 보존하고 다른 달 일회성 내역 보기와 접힌 수식 도움말을 제공한다.
- 기존 plan은 브라우저에서 단일 sheet 초안으로 투영하고 원본 DB 레코드를 변경·삭제하지 않는다. 사용자가 편집하여 저장할 때 sheet와 importedPlanIds를 같은 CAS 저장에 포함하여 재적재/중복 합산을 방지한다. 기존 버전별 금액과 납부 이력을 보존한다. 별도 반복 관리 화면은 제거하고 일반 수입·지출은 기존 기록이 있을 때만 보관함으로 남긴다. 운영 DB 마이그레이션·테스트 쓰기 없음.
- **입력표 열 너비:** 대표 요청에 따라 행 76/항목 210/날짜 190/금액 각 150/완료 90/관리 230px로 내용 기준 배분하고 나머지는 메모에 할당한다. 최소 표 폭 1296px에서 메모 200px를 확보하며 작은 화면은 기존 표 내부 가로 스크롤을 유지한다. 날짜 10자리+44px 달력, 금액 천 단위 쉼표+원, 관리 버튼 두 개+상태 한 줄을 기준으로 계산했다. 오류 안내만 줄바꿈을 허용한다.
- **상단 요약 금액 기준:** 이번 달·다음 달 및 예상 총지출·납부 완료·남은 금액 카드도 body(14px) 굵게로 통일한다. 모바일에서도 동일하며 이전 상단 카드 크기 유지 방침을 대체한다.
- **명세 카드 색상·위계 보정:** 카드 전체를 기존 s2 베이지 배경으로 채우고 열 제목 행은 s1 흰색으로 표시한다. 13px 축소는 상세 목록에만 적용하며 월/합계 줄은 기존 body(14px), 합계 굵기를 유지한다.
- **월별 명세 카드:** 펼친 월은 합계와 내역을 단일 테두리 컨테이너 안에 표시한다. 카드 내 텍스트는 meta(13px), 금액은 우측 정렬, 합계는 굵게 표시한다. 중복 총액 제목을 제거하고 항목 버튼 외곽선을 없애 명세서형 목록으로 정리한다. 원본 이동·접기·월 전환·자동 집계는 유지한다.
- **타이포 기준 재확정:** 아래 16/18/20px 확대 방침을 대체한다. 월별·상세 표는 기존 입력표와 같은 body(14px), 제목은 기존 title-sm(16px), 안내는 caption(12px). 합계는 주변 텍스트 크기를 유지하고 굵기만 강조한다. 기존 상단 요약 카드 크기는 유지. 앞으로 같은 페이지의 동급 요소를 먼저 비교하고 독립적인 확대를 하지 않는다. 월 행 아래 상세와 행 번호 보조 문구 제거는 유지한다.
- **상세 위치·가독성 수정:** 대표 캡처 기준으로 별도 상세 박스를 없애고 월별 표에서 선택한 월의 합계 행 바로 아래에 상세를 삽입한다. 같은 월을 다시 누르면 접고 다른 월은 그 행 아래로 전환한다. 본문 표 16px 토큰, 안내 14px, 월/연간 합계 18px 굵게, 상세 총액 20px 굵게. `지출표 N행` 및 기존 예정 지출 보조 표시는 제거하되 항목 클릭 원본 이동 기능은 유지한다.
- 검증: 선택 월 행 바로 다음에 상세 1개만 배치, 월 전환/다시 눌러 접기/원본 이동 확인. 글자 16px 및 월 합계 18px·700 굵기, 행 번호 보조 문구 없음 확인. 기존 13개 검사 통과. 모바일 390px 문서 375px, 표 안 스크롤 유지. 운영 데이터 변경·실물 기기 검증 없음.
- **월별 상세 펼침:** 월별 요약 행/금액 또는 이번 달·다음 달 카드 클릭 시, 요약표 아래·입력표 위에 선택 월 상세를 펼친다. 처음에는 닫힘, 다른 월 선택 시 갱신, 상세 접기 제공. 항목·납입기한·예상 지출·납부 상태를 기한순으로 표시하며 실제 납부액을 사용해 위 예상 총지출과 일치시킨다. 미완성 행도 확인 대상으로 표시하고 합계용 행/다른 월은 제외한다.
- 상세는 표 행과 기존 예정 지출을 함께 포함한다. 표 항목 클릭은 정렬 상태와 무관하게 원래 행으로 이동·강조·포커스한다. 기존 예정 항목은 해당 월의 기존 관리 영역을 펼쳐 원본으로 이동한다. 조회/이동은 저장을 발생시키지 않는다. 데이터 구조·게이트 변경 없음.
- 상세 검증: 총 13개 테스트 통과. 모의 화면에서 월 전환/접기, 빈 월, 원본 이동, 정렬 후 정확한 행 포커스, 기존 반복 비용 포함·원본 연결 확인. 실제 납부 변경 후 상세/합계 즉시 일치(350→330원), 모바일 문서 375px/뷰포트 390px 내부 표 스크롤 확인. 운영 DB 쓰기 및 실물 기기 검증 미실시.
- **항목/납입기한 정렬:** A·B 열 제목 버튼으로 오름차순/내림차순 전환, 방향 표시와 aria-sort 제공. 한 번에 한 열을 기준으로 정렬한다. 같은 값은 원래 순서, 빈 값과 합계용 행은 아래에 둔다. 보기 순서만 바꾸고 저장 행 순서·행 번호·수식 참조는 유지한다. Enter는 정렬된 화면의 다음 행으로 이동한다. 정렬 자체는 데이터 저장을 발생시키지 않는다.
- 정렬 검증: 총 12개 테스트 통과(양방향/빈칸/합계/안정 정렬/수식 보존). 모의 브라우저에서 항목 가나다순 및 납입기한 역순, 정렬 후 Enter, 값 수정에 따른 참조·합계 갱신 확인. 모바일 390px 문서 375px. 운영 DB 쓰기와 실물 기기 검증은 미실시.
- **월별 자동 연동 보정:** 다른 월의 미완성 행 때문에 모든 월 합계를 감추지 않는다. 오류/미완성 여부를 납입기한 월별로 판단하여 정상 월은 즉시 표시, 해당 월만 `입력 중 · 확인 필요`로 안내한다. 이번 달/다음 달, 선택 월 상세, 연간 요약에 동일 적용. 월을 정할 수 없는 날짜는 제외 건수를 별도로 안내하며 연간 합계를 확정하지 않는다. 합계용 행 자체의 오류는 월별 지출을 막지 않되, 실제 지출 수식으로 전파된 오류는 해당 월에서 표시한다.
- 검증: 미완성 10월·정상 9월 분리, 날짜 미지정, 잘못된 날짜, 월을 넘는 수식 오류 등 포함 11개 테스트 통과. 모의 화면에서 9월 81,930원 유지, 10월 229,760원 입력 즉시 연간 311,690원 갱신 및 상세 요약·자동 저장 재조회 확인. 모바일 390px 문서 375px. 운영 DB 검증 쓰기/실물 기기 검증 없음.
- **Tab 이동 보정:** 보이지 않는 네이티브 달력 입력기는 Tab 순서에서 제외하여 B 납입기한→C 예정 금액으로 바로 이동한다. 달력 클릭은 유지하고 B칸 Alt+↓로도 선택기를 연다. 달력 클릭 후 Tab/Shift+Tab은 C/B로 복귀한다. 모의 브라우저에서 A~F 순방향·역방향, 달력 showPicker 성공 및 복귀 확인. 기존 수식·날짜 8개 검사 통과.
- **2026-08-31 자동 저장 UX 확정:** 화면 행 번호·수식은 1부터 시작. 기존 저장 수식의 2번 기준은 읽기/입력 경계에서 변환하여 원본과 참조 의미를 보존한다(운영 데이터 일괄 변환 없음). 행 추가는 표의 왼쪽 열 `+` 및 하단 추가 줄로 이동한다. 평상시 수동 저장·재조회·변경 경고는 없애고 표 오른쪽 위에 저장 상태만 표시한다.
- 입력 중단 800ms 또는 셀 이탈 시 자동 저장. 구조가 유효한 작성 중 행/수식도 저장해 빈칸 때문에 다른 입력을 잃지 않게 하되, 오류가 있으면 합계 확정 대신 확인 필요를 표시한다. 아래의 수동 저장/수식 오류 저장 금지 정책을 이 항목으로 대체한다. 저장 중 입력은 허용하고 스냅샷별 순차 저장, revision 충돌 방어 유지. 실패 시 입력 보존 및 재시도/명시적 변경 폐기 후 재조회만 제공한다.
- 자동 저장 검증: 수식·날짜·월별 집계 8개 테스트 통과. 모의 저장/재조회에서 1번 행·쉼표 금액·C1 수식·SUM 유지 확인. 지연 응답 중 입력 가능 확인, 후속 최신 금액 재조회 확인. 503 실패와 충돌 시 입력 보존 및 실패 안내 확인. 모바일 390px 문서 375px. 운영 DB 검증 쓰기와 실물 기기 검증은 하지 않는다.
- 금액은 입력칸 내부에서 천 단위 쉼표 + 원으로 단일행 표시한다. 숫자의 하단 중복 출력과 빈 실제 납부액의 0원은 숨긴다. 수식은 원문과 계산 결과를 유지하며 저장 숫자에는 표시용 쉼표를 넣지 않는다.
- 월별 예상 지출 표: 조회 연도의 1~12월 예상 지출·납부 완료·남은 예정 및 연간 합계. 이전/다음 연도 이동, 월 클릭 시 기존 상세 요약 연동. 납입기한 기준이고 기존 반복 예정도 합산하며 합계용 행은 제외한다. 예상 지출은 실제 납부 + 미납 예정이며 저장 전 편집값도 반영한다. 데이터/게이트 변경 없음.
- 검증: 기존 수식·월별 집계 7개 테스트 통과. 모의 브라우저에 대표 예시 5개월 입력, 2026년 767,800원 / 2027년 225,950원 분리 확인. 9월 실제 납부 80,000원 시 2026년 예상 765,870원으로 갱신, SUM 합계 행 추가에도 월별 이중 집계 없음. 쉼표 표시·빈 값 숨김·모의 저장 후 재조회 확인. 390px에서 문서 375px, 월별 표 310px로 가로 넘침 없음. 운영 데이터 쓰기·실물 휴대폰 검증은 미실시.

- 대표 승인: 행 추가·삭제·복사, 간단한 수식·자동합계·사칙연산 방식으로 수정.
- A 항목 / B 납입기한 / C 예정 금액 / D 실제 납부액 / E 납부 완료 / F 메모. 모든 달의 행을 한 표에서 편집하고 ‘표 저장’으로 반영. 월별 요약만 납입기한으로 나눈다. Enter 다음 행, Tab 다음 칸.

- 합계용 행은 월별 지출과 표 하단 자동합계에서 제외해 이중 집계를 방지. 행 삭제 시 참조 이동, 직접 삭제 셀은 #REF!. 복사는 상대 참조 이동, 실제 납부액과 완료 상태 초기화. 행 번호 2부터, 최대 500행.
- 지출표는 같은 owner/private/settings 범위의 단일 메모(sheet payload)로 원자 저장. 임의 revision UUID를 비교하는 낙관적 잠금, 최초 저장은 고정 UUID로 중복 표 생성 방지. 기존 plan/entry 행은 변환·삭제하지 않고 하단 접기 영역에서 계속 관리하며 plan은 월별 요약에 합산.
- 편집 중 임시값임을 표시하며 실패 시 입력 유지. 페이지 이탈 시 브라우저 경고. 다른 기기 수정과 충돌하면 저장을 중단하고 재조회 안내. 운영 DB 검증 쓰기·DDL·RLS 변경 없음.

## 예정 지출 중심 개편
- 대표 목적: 이번 달·다음 달의 고정지출과 예상 금액을 케어 일정처럼 미리 확인. 수입·지출 기록은 하단 접기 영역에 보존.
- 고정지출은 항목·매월 결제일·시작 월·예상 금액을 한 번 등록하면 조회 월별로 계산해 표시한다. 날짜별 거래를 DB에 미리 생성하지 않는다. 29~31일이 없는 달은 말일 적용.
- 일회성 예정 지출은 지정 날짜에만 표시한다. 이번 달/다음 달 요약, 선택 월 날짜별 예정 목록, 납부 완료/실제 금액/납부일/납부 취소 제공.
- 예상 총지출 = 이미 납부한 실제 금액 + 미납 예상 금액. 일반 수입·지출 기록과는 별도 집계하며 화면에 명시. 월별 납부 상태는 서로 독립적이다.
- 같은 비공개 메모 키 안에 plan payload를 추가한다. 기존 entry payload와 운영 데이터는 변환하거나 삭제하지 않는다. 예상 금액 수정은 선택 월 이후 버전으로 보존하며 반복 중단은 종료 월로 처리한다. 이미 납부한 달의 실제 금액은 보존한다.
- plan 변경은 읽은 legacy_payload와 일치할 때만 PATCH하는 낙관적 잠금으로 다른 기기의 변경을 조용히 덮어쓰지 않는다. DB/RLS/권한 변경 없음. 운영 저장 테스트 없음.
