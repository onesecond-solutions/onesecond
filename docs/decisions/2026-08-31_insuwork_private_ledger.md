# 임태성 전용 간단 가계부

- 대표 요청: “임태성 게이트에 너무 복잡하지 않은 가계부를 만들어줘, 나만 사용할거야.”
- 보험워크 전용, onesecond 저장소. 다른 제품은 수정하지 않는다.
- 지정 user_id 98c5f4f9-10c1-4ee1-a656-5c2ca63239fd와 로그인 세션이 있을 때만 PC/모바일 메뉴와 화면 허용. 직접 URL과 데이터 요청에서도 재확인한다. 관리자 전체/테스트 계정 예외 없음.
- 날짜·수입/지출·원 단위 금액·분류·내용 입력, 월별 수입/지출/차액, 내역 수정·삭제. 카드 연동·예산·차트 없음. 빈 상태로 시작한다.
- 기존 insuwork_items 비공개 memo를 재사용한다. 각 거래를 별도 행으로 저장하고 legacy_payload.workspace_category=settings, setting_key=personal_ledger_v1로 일반 자료·즐겨찾기에서 제외한다. 기존 owner_id RLS가 서버 데이터 경계이며 클라이언트 메뉴 게이트를 보안 경계로 간주하지 않는다.
- 신규 DDL·권한·RLS 변경 없음. 운영 DB에 검증용 거래를 쓰지 않는다. 테스트는 모의 저장소에서 실행하며 라이브는 조회와 화면만 검증한다.
- 사용자 저장은 private/owner_id 고정, 수정·삭제도 owner_id/setting_key/private/id 필터 적용. 삭제는 deleted_at 설정. 조회 실패를 0원으로 표시하지 않으며 실패한 입력은 보존한다. 신규 저장 재시도는 동일 UUID로 중복 생성 방지.
- 계정 저장 방식이므로 같은 계정의 PC·휴대폰에서 조회할 수 있다. 금융 데이터는 공개 JSON·저장소·로그에 넣지 않는다.
