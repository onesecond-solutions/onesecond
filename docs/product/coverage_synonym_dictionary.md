# 보험워크 보장분석 담보명 동의어 사전

## 기준

- 표준명은 2026-09-11 임태성 게이트의 저장된 기본 양식에서 직접 추출한 담보명을 기준으로 한다.
- 보험사 특약명은 지우거나 표준명으로 바꾸지 않는다. 원문 특약명과 표준 담보명을 함께 저장한다.
- 자동 연결은 `data/coverage_synonyms.json`에 확정된 표현만 사용한다.
- 사전에 없는 표현은 유사도만으로 합치지 않고 `미분류`로 보존한다.
- 갱신형, 지급 횟수, 감액, 급여 여부, 질환 범위 등 괄호 조건은 동의어 판정에서 제거할 수 있어도 원문 데이터에서는 유지한다.

## 자동으로 합치면 안 되는 표현

- `고액(표적)항암치료비`는 여러 신치료 담보를 합산한 요약값이다. 표적·세기조절·양성자·중입자·CAR-T 중 하나에 넣지 않는다.
- `3대비급여실손`은 도수치료·주사제·MRI의 합산 행이다. 개별 담보와 동시에 합산하지 않는다.
- `통합암 치료비`, `암주요 치료비`, `비급여 암주요 치료비`는 지급 조건 확인 전 각각 유지한다.
- `CI 진단비`는 일반암 진단비와 합치지 않는다.
- `뇌심장 주요 치료비`와 `특정 순환계질환 주요 치료비`는 각각 유지한다.
- `벌금(대인/스쿨존/대물)`은 요약 행이다. 세부 담보에 금액을 임의 분배하지 않는다.
- `가족생활배상책임`, `가족 일상생활 배상책임`, `가족/일상/자녀배상`은 피보험자 범위가 다를 수 있어 `일상생활배상책임`과 자동 통합하지 않는다.
- `고액암`은 대표님이 기본 암 양식에서 삭제하도록 확정했으므로 원문 추적용으로만 보존하고 기본 양식에 자동 추가하지 않는다.

## 기본 양식에서 발견한 교정 대상

- `비금여 암주요 치료비` → `비급여 암주요 치료비`
- 양시진 원본의 `압 입원비` → `암 입원비`
- `후유 장애`, `후유장애` → 보험 담보 표기인 `후유장해`
- 대분류 `수술`과 `수술비` → `수술비`
- 대분류 `운전`과 `운전자` → `운전자`

기본 양식에는 과거 파일 가져오기로 추가된 분류와 담보가 섞여 있다. 이 사전은 현재 표현을 기록하되, 기본 양식 자체를 자동 정리하거나 삭제하지 않는다. 대표님 확인 후 별도 변경 이력을 남기고 교정한다.

## 2026-09-12 실손 적용 기준

- 실손 표준명은 `질병 입원 의료비`, `질병 통원 의료비`, `상해 입원 의료비`, `상해 통원 의료비`로 표기를 통일한다.
- 입원·통원 통합, 급여·비급여 및 중증·비중증 담보는 해당 범위를 명칭에 유지한다. 비급여 3종은 도수·체외충격파·증식치료 / 주사료 / MRI·MRA로 구분한다.
- `질병실손의료비`, `상해실손의료비`는 범위가 불명확하므로 원문 그대로 보존한다. 입원으로 자동 치환하지 않는다.
- 실손 동의어는 괄호 조건을 제거한 느슨한 연결을 사용하지 않는다. 확정된 표현만 연결한다.
- 대분류는 실손, 중분류는 명시된 1~5세대 또는 세대 확인이다. 세대는 담보명·가입일로 추측하지 않는다.
