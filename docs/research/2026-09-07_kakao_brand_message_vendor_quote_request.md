# 보험워크 카카오 브랜드 메시지 공급자 견적요청서

작성일: 2026-09-07  
용도: 보험워크의 월별 인사·생일 축하·고객 안내용 카카오 브랜드 메시지 공급자 비교

## 1. 진행 순서

1. 아래 공통 견적요청서를 SOLAPI, 비즈고, 비즈뿌리오, NHN Cloud에 동일하게 전달한다.
2. 월 1천·5천·1만·5만 건 구간을 모두 요청한다.
3. 전화 설명만으로 결정하지 않고 단가, 과금 조건, 약정 및 개인정보 조건을 이메일이나 견적서로 받는다.
4. 회신 내용을 문서 하단 비교표에 입력한다.
5. 테스트 계정에서 내부 직원 5~10명에게 텍스트형·이미지형·실패 대체발송을 시험한다.
6. 실제 월 예상비용과 계약 조건을 확인한 뒤 공급자를 선정한다.

## 2. 공급자에게 보낼 공통 견적요청서

### 제목

`[견적 요청] 보험워크 카카오 브랜드 메시지·알림톡 API 연동`

### 본문

안녕하세요.

보험설계사 업무관리 서비스 **보험워크**에 카카오 비즈메시지 발송 기능을 연동하려고 합니다. 공급자별 조건을 동일한 기준으로 비교하기 위해 아래 조건의 견적과 기술·계약 자료를 요청드립니다.

#### 서비스 개요

- 서비스명: 보험워크(Insurance Work)
- 운영 주체: [회사명 입력]
- 담당자: [담당자명 입력]
- 연락처: [전화번호 입력]
- 이메일: [이메일 입력]
- 연동 방식: REST API 또는 공식 SDK
- 사용 목적
  - 브랜드 메시지: 월별 인사, 생일 축하, 계절 안내, 보험 관련 생활정보
  - 알림톡: 보험금 청구 접수·보완·처리 안내, 보험료 납입·만기·갱신 안내, 상담 예약 알림
  - 개별 보험 상담: 발송 시스템을 사용하지 않고 담당 설계사의 개인 카카오톡으로 진행

#### 예상 발송량

- 초기: 월 500~1,000건
- 운영 안정화 후: 월 3,000~5,000건
- 확대 시 비교 기준: 월 10,000건 및 50,000건
- 월별 인사는 월 1회 예약 또는 일괄 발송
- 알림톡은 고객 이벤트 발생 시 개별 발송

#### 요청 단가

아래 항목을 **성공 건당 단가, 부가세 별도 기준**으로 회신해 주십시오.

1. 브랜드 메시지 텍스트 템플릿형
2. 브랜드 메시지 텍스트 자유형
3. 브랜드 메시지 이미지형
4. 브랜드 메시지 와이드 이미지형
5. 채널 친구 발송 단가
6. 채널 비친구이지만 카카오톡 광고성 정보 수신에 동의한 고객의 확장 발송 단가
7. 알림톡 단가
8. 실패 시 SMS·LMS 대체발송 단가
9. 월 1천·5천·1만·5만 건별 할인 단가
10. 월 기본료, 가입비, 최소 충전액, 최소 이용기간, 해지수수료

#### 과금·발송 정책 확인

1. 성공 건만 과금하는지, 요청·실패·대체발송별 과금 기준
2. 브랜드 메시지 실패 시 원 메시지 요금 환불 여부
3. 같은 고객에게 중복 요청됐을 때 중복 차단 기능 제공 여부
4. 예약 발송 취소 가능 시점과 취소 수수료
5. 발송 지연 시 메시지 유효시간 설정 또는 지연 메시지 자동 폐기 가능 여부
6. 일·월 발송 한도와 한도 상향 절차
7. 무료 수신거부 번호 제공 여부와 비용

#### 카카오 이용 조건 확인

1. 카카오톡 채널 친구 대상과 비친구 확장 대상의 요건
2. 광고성 정보 수신동의 증빙 등록 방법
3. 기존 고객의 수신동의 자료 일괄 등록 가능 여부
4. 수신거부 고객 자동 제외 기능과 API 제공 여부
5. 템플릿 등록·수정·심사 비용 및 평균 소요일
6. 월별 인사 문구를 매달 변경할 경우 템플릿형 또는 자유형 중 적용되는 상품
7. 보험업종에서 허용·제한되는 문구와 별도 심사자료

#### 기술·운영 자료 요청

1. API/SDK 문서와 테스트 계정 또는 샌드박스
2. 발송 결과 웹훅, 재시도 정책, 상태코드 문서
3. API 호출 제한과 대량 발송 권장 방식
4. 월 가동률 SLA, 장애 통지 시간, 장애 보상 기준
5. 기술지원 운영시간과 긴급 장애 연락처
6. 공급자 변경 시 발신프로필·템플릿 이전 가능 여부

#### 개인정보·보안 자료 요청

1. 개인정보 처리위탁 계약서 또는 표준 특약
2. 수신번호·메시지 본문·이미지·발송기록 보관기간
3. 계약 종료 시 삭제 절차와 백업 삭제기간
4. 개인정보 제3자 제공·재위탁 업체 목록
5. 국내 저장 여부와 국외 이전 여부
6. 관리자 접근통제, 접속기록 및 암호화 방식
7. 보안 인증서, 침해사고 통지 기준 및 최근 장애 이력

가능하다면 위 항목이 포함된 견적서와 계약서·약관 샘플을 이메일로 부탁드립니다. 전화 안내를 주시는 경우에도 최종 단가와 계약 조건은 문서로 회신해 주시면 감사하겠습니다.

## 6. 공급자 선정 후 보험워크 구현 원칙

- 공급자 API 키는 브라우저에 두지 않고 서버 함수의 비밀값으로만 보관한다.
- 고객별 광고 수신동의 일시·방법·철회 이력을 저장한다.
- 브랜드 메시지는 동의 고객만 선택되도록 서버에서 재검증한다.
- 발송 전 예상 인원·예상 비용·문구·예약시간을 최종 확인한다.
- 동일 캠페인과 고객 조합에 멱등키를 사용해 중복 발송을 막는다.
- 광고성 발송 가능 시간 밖에는 예약 자체를 차단한다.
- 대체발송은 메시지 유형별 명시적 선택으로만 사용한다.
- 병력, 진단명, 주민등록번호, 계좌번호, 증권번호 전체는 메시지에 포함하지 않는다.
- 공급자를 교체할 수 있도록 보험워크 발송 로직과 업체별 API 어댑터를 분리한다.
