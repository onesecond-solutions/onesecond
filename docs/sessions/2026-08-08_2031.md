# 세션 인계 — 데이폴더 웹버전 1차 레이아웃 정리

## 제품 방향 확정

- 데이폴더 웹버전을 먼저 완성한다.
- 완성된 웹버전을 기준으로 설계사 버전을 만들고 보험브리핑에 연결한다.
- 이후 웹버전을 독립 다운로드 앱으로 패키징한다.
- 반응형·모바일 사용과 PC↔모바일 데이터 연동은 필수다.
- 임태성 데이폴더에 축적된 자료 중 공개 승인된 자료를 보험브리핑 공용 콘텐츠의 원천으로 사용한다.

## 오늘 완료

- 캘린더 상단 2단 구조를 한 줄 중심으로 정리하고 실제 캘린더 높이를 확대했다.
- PC에서는 사이드바를 완전히 접고 펼칠 수 있는 경계 토글을 추가했다.
- 모바일에서는 사이드바가 본문 위에 열리는 드로어 기반을 적용했다.
- 웹버전에 맞지 않는 브라우저 저장 안내와 다운로드 메뉴를 화면에서 제거했다.
- 오늘·이전·다음·현재 월을 로고 옆으로 이동하고 검색창을 중앙에 배치했다.
- 현재 시각과 연간·오늘 진행률 표시를 제거했다.

## 현재 실제 상태

- 서버 저장, 로그인, 계정별 데이터 동기화는 아직 구현되지 않았다.
- 화면 문구는 웹버전 기준으로 정리했지만 실제 데이터 저장은 현재 브라우저 로컬 저장소를 사용한다.
- PC 캘린더와 사이드바 접기, 모바일 드로어 기반까지 구현됐다. 모바일 전체 화면 최적화는 계속 필요하다.

## 다음 세션 우선순위

1. `main`을 pull하고 라이브 화면과 저장소 상태를 확인한다.
2. 기존 저장 로직에 서버 저장 어댑터를 끼울 수 있도록 데이터 경계를 먼저 정리한다.
3. 로그인 화면에 종속되지 않게 캘린더·노트·자료함의 반응형·모바일 UI를 계속 완성한다.
4. 계정별 서버 저장과 PC↔모바일 동기화 사양을 확정한다. 운영 DB DDL·데이터 쓰기는 승인된 CI 채널로만 진행한다.
5. 웹버전 안정화 후 설계사 버전과 보험브리핑 공개자료 연결 구조를 구현한다.
