## 실손에서 대표와 확정한 내용

- 대분류 `실손`, 중분류 `1세대 실손`~`5세대 실손`, 명시적 근거 없으면 `세대 확인`.
- 대분류와 중분류 가로 병합 금지. 화면과 선택 이미지 복사 모두 분리.
- 질병/상해 각각 입원 의료비·통원 의료비 표기 통일. 비급여 도수·체외충격파·증식치료, 비급여 주사료, 비급여 MRI·MRA 표기 통일.
- 입원·통원 통합 / 급여·비급여 / 중증·비중증은 조건을 유지한다.
- 대표가 처음 “질병실손의료비=질병 입원 의료비, 상해실손의료비=상해 입원 의료비”라고 했지만 이후 인터넷 조사 결과를 보고 **범위 불명확한 명칭은 원문 유지하는 방식**으로 구현 승인했다. 자동 입원 연결로 되돌리지 않는다.
- 현재 화면에서 질병실손의료비·상해실손의료비가 남아 있는 이유도 대표에게 설명했다.
- 상품/행에 명시된 세대만 사용. 세대 추정 엔진 아님. 자료에서 세대가 추출되지 않으면 `세대 확인` 유지.
- 서로 다른 세대는 행 분리. 혼합 행 분리 시 상품값 보존, 원본 합계는 sourceTotal로 보존하고 분리행 합계는 비워 중복 배정 방지.
- 기존 양식을 읽을 때 normalize로 표시 정리. DB 일괄 마이그레이션 안 함. 기본 양식 편집저장 시 기존 이전버전 보존 경로 사용.

## 운전자 정리 제안 — 아직 미반영

대분류 `운전`/`운전자` → `운전자`는 대표의 확정 의도다. 아래 중분류/담보명은 Codex가 제안한 내용이며 대표가 세부안을 최종 선택한 것은 아니다.

| 대분류 | 중분류 | 담보명 제안 |
|---|---|---|
| 운전자 | 교통사고처리지원금 | 교통사고처리지원금 |
| 운전자 | 교통사고처리지원금 | 교통사고처리지원금(사망) |
| 운전자 | 교통사고처리지원금 | 교통사고처리지원금(중상해) |
| 운전자 | 교통사고처리지원금 | 교통사고처리지원금(6주 미만·중대법규위반) |
| 운전자 | 변호사선임비용 | 자동차사고 변호사선임비용 |
| 운전자 | 벌금 | 자동차사고 벌금(대인) |
| 운전자 | 벌금 | 자동차사고 벌금(대물) |
| 운전자 | 부상치료비 | 자동차사고 부상치료비 |

주의:
- 자료에 존재하는 담보만 해당 행으로 연결. 일반 처리지원금 한도를 사망/중상해에 복제하지 않는다.
- 스쿨존: 대인 벌금에 포함된 한도인지 별도 추가보장인지 확인.
- 변호사: 경찰조사 포함, 심급별 한도, 자기부담금 조건을 보존.
- 부상: 부상등급 범위/특정 등급 기준금액을 보존.
- 어제 사전의 `중상해교통사고처리지원금` → 일반 `교통사고 처리지원금` alias는 조건 유실 우려로 재검토 필요.
- 현재 실손만 느슨한 괄호 제거 연결을 막았다. 운전자도 조건이 지워지지 않도록 coverageSynonym/coverageMatchKey를 점검할 것.
- `corrections`에 운전→운전자가 기록돼 있다고 해서 현재 화면에 자동 적용되고 있다는 뜻은 아니다. 렌더 normalize/수동 저장/가져오기 각각 확인.

## 코드 진입 지점과 검증

- `js/insuwork-coverage.js`: normalize, normalizeSilsonRows, silsonName, silsonGeneration, mergeImportedRecord, workspaceHtml, setMergedField, coverageImageBlob.
- `js/insuwork.js`: 저장 양식 읽기/쓰기, 고객별 원장, 이력 저장, 게이트.

- 검사: `node --check js/insuwork-coverage.js`, `node --test scripts/insuwork-silson.test.cjs`.
