## 4. OCR 재사용 조사 (파일명 자동생성 = 미착수, 배포 blocker)
- 대표 요청: 데이폴더에 **파일명 없는 파일(붙여넣기 스샷·카톡·image.png) 드롭/붙여넣기 → 내용 인식해 자동 파일명**.
- 조사 결과 **기존 Gemini OCR 인프라 이미 있음**: `gemini-customer-ocr`(base64→고객필드), `ocr-extract`(fileUrl→전체텍스트), `quick-card`(텍스트/이미지→{title}), `gemini-card`. `GEMINI_API_KEY`·CORS·Supabase URL/anon(`js/db.js`) 재사용 가능.
- 데이폴더 파일 흐름: `ju()`가 `title=파일명-확장자`로 저장(IndexedDB blob + `date-archive-items-v1`). **붙여넣기 핸들러 없음**(충돌0). 오버라이드로 "파일명 바꿔 앱에 넘기기"(붙여넣기 리스너 + 무의미 파일명 시 드롭 capture 차단 + 리네임 File 합성 드롭) 가능 판정 — 단 합성 DragEvent 전달 라이브 검증 필요.
- **필요: base64→{title} 소형 신규 함수 `file-title`**(기존 함수 조합). 승인은 받았으나 **엣지함수 배포 채널 없음**이 blocker → 배포 방법 결정 대기.
