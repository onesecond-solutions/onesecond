## 2. 영업방향·전략 4파일 적재 (전부 published·썸네일 有)
대표가 카톡으로 파일 전달 → 총괄이 내용 파악·제목 정리·PPT→PDF 변환·적재. 스크래치패드 `ss_ingest/`(ingest.py·verify_publish.py·thumbs.py·ingest_hanwha.py, UTF-8 urllib — bash+curl은 한글 JSON 깨짐 PGRST102).
- **생명** 흥국생명 · 8월 교안 · 암플랜 (김태우) — 원본 PDF(preview=원본)
- **손해** KB손해보험 · 8월 교안 · 마케팅 전략 (김대근) — PPT→PDF
- **손해** 메리츠화재 · 8월 영업방향 · 더원 시청 TM (김영철 AM) — PPT→PDF *(회사 분류=대표 확정 "메리츠화재")*
- **손해** 한화손해보험 · 8월 교안 · 상품전략 — 원본 PDF
적재 흐름: 업로드→INSERT(reviewing)→서명 fetch 검수(200)→published→썸네일. **썸네일=소식지와 동일** `newsletters` 버킷 `thumbs/<sales_strategy_id>.jpg`(미리보기 PDF page1, w320·jpg q72, PyMuPDF). 렌더는 이미 배선(`_ssEagerThumbs`→`_ssThumbOne`→`_svSignUrl('newsletters', thumbs/<id>.jpg)`→`_nlThumbImg`). ⚠️anon은 서명 불가라 게스트 테스트엔 썸네일 안 뜸(로그인 대표는 뜸).

## 3. 소식지·영업전략 미리보기 페이지별 ⚡복사 버튼 (#1556)
대표: "미리보기 페이지를 자동 캡처/복사해 카톡 전송(이미지 미리보기 딸깍처럼)."
- 공용 헬퍼 `_hubPageCopy(cv)`: `canvas.toBlob('image/png')`→`navigator.clipboard.write([ClipboardItem])`+toast. 기존 `copyCardImage`/`doCopy` 검증 패턴 재사용.
- `_hubSsCanvasRender`(영업전략)·`_hubNlCanvasRender`(소식지) 페이지 루프에 래퍼 `.hub-pgwrap`+버튼 `.hub-pgcopy`(우상단 반투명). IIFE 클로저로 페이지별 canvas 정확 캡처. `page.render`는 기존대로 cv 대상(무결).
- **"새 탭에서 열기"는 브라우저 네이티브 PDF 뷰어라 우리 버튼 불가** → 인앱 미리보기에만. 대표 "이대로 사용" 결정(전체화면 뷰어 추가 보류).
- ⚠️실제 클립보드 복사는 로그인 서명 필요라 총괄(게스트)이 최종 클릭 검증 못 함 — 대표 라이브 확인 요청함(Windows/Chrome은 copyCardImage와 동일 동작).
