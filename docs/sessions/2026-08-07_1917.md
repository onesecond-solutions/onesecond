### 1-1. 제작 방식
원본 PNG에서 PyMuPDF로 ①이름/번호/주소 영역을 인접 배경색으로 인페인팅한 **빈 템플릿** + ②아이콘3(전화/스마트폰/팩스) crop → base64. canvas에 템플릿 깔고 텍스트(맑은고딕 malgunbd) + 아이콘 스프라이트 재배치. 폰트·좌표 검증 = Python fitz 합성 렌더 + 브라우저 canvas 실렌더.

### 1-2. 독립 HTML 버전
`C:\Users\az\Downloads\명함만들기.html`(자기완결, 대표 전달). 파일만 보내면 누구나 브라우저로 입력→PNG 저장→카톡 전송. 최종=가로/세로 토글본(3.8MB, h+v 자산 내장).

### 1-3. 핸드폰 숨김 레이아웃 기획(대표 승인)
