### 0-3. 공개 화면 구조

- 홈 이후 카테고리와 문서는 정적 HTML 계열로 연결한다.
- `app.html` 부팅에 의존하지 않는다.
- iframe은 사용하지 않는다.
- 빈 컨테이너를 먼저 내려준 뒤 JS로 목록이나 본문을 생성하는 방식을 사용하지 않는다.
- 카테고리 목록과 문서 본문은 최초 HTML에 포함한다.
- 문서 제목을 클릭하면 제목 바로 아래에 본문이 펼쳐진 화면을 제공한다.
- 검색기와 6개 주제 탭은 문서를 펼친 뒤에도 화면 구조 안에 유지한다.
- 스크롤 시 sticky 적용 여부는 이번 범위에서 확정하지 않는다.

### 0-4. 기존 SPA와 게이트

- 기존 `axis-*` SPA 카테고리는 삭제하지 않는다.
- `app.html:6211`의 `showView` 통합 게이트는 이번 작업에서 수정하지 않는다.
- `_canSeeCoverage()`는 수정하지 않는다.
- bojang, cov-medical, X-FILE 게이트는 무접촉 유지한다.
- 공개 홈 카드의 노출 조건과 클릭 목적지만 수정한다.
- 로그인 내부 `axis-*` SPA는 기존 상태를 유지한다.

### 0-5. 설계사 전용 자료

`[설계사 전용 자료 보기]` 버튼은 필요한 구조로 확정한다.

- 비로그인: 버튼 DOM 없음
- 로그인 + 열람 권한 없음: 버튼 DOM 없음
- 로그인 + 열람 권한 있음: 버튼 노출
- 클릭 시 공개 본문 아래에 설계사 전용 레이어 펼침

단, 실제 콘텐츠 수정과 분리는 대표님이 별도 지시한다.

총괄은 다음을 지킨다.

- 전용 내용을 임의로 작성·수정·요약하지 않는다.
- 전용 내용은 공개 HTML에 포함하지 않는다.
- 전용 내용은 공개 JS나 `knowledge-registry.js`에 넣지 않는다.
- 승인된 전용 콘텐츠와 보호 저장 위치가 없는 문서에는 버튼을 만들지 않는다.
- 빈 버튼과 준비 중 화면을 만들지 않는다.

# WO-3. 비로그인 홈 카드 노출 및 연결

## 대상

`js/home.js`의 공개 카드 6개.

## 작업

6개 카드를 비로그인에게 모두 노출하고 다음 정적 경로로 연결한다.

```text
의료실비   → /insurance/silson/
암         → /insurance/cancer/
뇌·심장    → /insurance/brain-heart/
수술비      → /insurance/surgery/
간병·치매   → /insurance/care-dementia/
기타        → /insurance/other/
```

## 금지

- `app.html:6211` 수정 금지
- `_canSeeCoverage()` 수정 금지
- bojang·cov-medical·X-FILE 게이트 수정 금지
- 기존 `axis-*` SPA 삭제 금지

## 원장 URL 처리

공개 문서의 대표 URL은 새 `/insurance/<slug>/`로 갱신할 수 있다.

이 경우 기존 SPA 카테고리에서 문서를 클릭하면 정적 공개 문서로 이동하는 동작을 1차에서 허용한다. SPA 전용 별도 링크 분기는 이번 범위에 넣지 않는다.

## 검수

- 비로그인 홈에서 6개 카드 전부 노출
- 각 카드 클릭 시 해당 정적 카테고리 도달
- 빈 카테고리는 공개 0건 상태 표시
- 보장분석·X-FILE·알릴의무 등 기존 게이트 무회귀
- 로그인 내부 `axis-*` SPA는 기존 상태 유지

## 롤백

# WO-6. 설계사 전용 자료 버튼

대표님이 별도로 수정·분리한 전용 콘텐츠와 보호 저장 위치가 준비된 문서부터 적용한다.

## 상태별 동작

| 상태 | 화면 |
|---|---|
| 비로그인 | 버튼 DOM 없음 |
| 로그인 + 열람 권한 없음 | 버튼 DOM 없음 |
| 로그인 + 열람 권한 있음 | `[설계사 전용 자료 보기]` 노출 |
| 버튼 클릭 | 공개 본문 아래 전용 레이어 펼침 |

## 필수 조건

- 공개 HTML에 내부 내용 0건
- 공개 JS에 내부 내용 0건
- `knowledge-registry.js`에 내부 내용 저장 금지
- 로그인 세션과 권한을 확인한 뒤 보호 데이터 요청
- 전용 배지, 구분되는 배경, 닫기 버튼 제공
- 전용 콘텐츠가 없는 문서에는 버튼 미생성

## 저장 위치 관문

현재 공개 문서에 1:1로 연결되는 보호 저장 위치는 확인되지 않았다.

보호 저장 위치가 없으면 기존 공개 테이블에 임의 저장하지 않는다.

신규 테이블 또는 기존 보호 테이블 활용이 필요할 경우 다음을 먼저 작성한다.

- 저장 구조
- 문서 연결 키
- RLS
- 역할·소속 권한
- 롤백안
- 기존 데이터 영향

대표님 별도 승인 후 진행한다.
