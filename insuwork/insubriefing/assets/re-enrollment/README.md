## 편집 원칙

- 세대명만으로 재가입 결과를 단정하지 않는다.
- 보험증권, 해당 상품 약관, 보험사 공식 안내문을 우선한다.
- 5세대 실손보험 공식 출시일은 2026년 5월 6일이다.
- 자동연장, 계약 종료, 철회 및 환급은 계약별 근거를 확인한 뒤 안내한다.
